01

실습 1 · 심박 측정 센서로 심박수 측정하기

교과서 67~68쪽 · 회로 구성, 프로그래밍, 실행 결과

쉽게 말하면센서는 심장 박동을 0~65535 사이의 숫자로 알려 줘요. 프로그램은 이 숫자를 전압으로, 다시 1분 동안의 심박수(bpm)로 바꿔서 정상인지 비정상인지 나눠요.

❤️ 정상 심박수의 범위 (67쪽)

심장 박동 측정값(심박 측정값)은 분당 심박수로 표시하며, 단위는 bpm(beats per minute)이에요. 일반적인 성인의 정상 수치 범위는 40~120bpm이에요.

운동을 하거나 활동 수준이 높을 때에는 수치가 높아질 수 있고, 개인의 건강 상태와 연령에 따라 정상 범위가 다를 수 있어요.

🔌 1 회로 구성 (67쪽)

심박 측정 센서와 피코를 아래 회로 연결 방법에 따라 연결해요.

심박 측정 센서피코
SGP28핀(아날로그 연결)
+3V3핀(전원 공급 VCC)
-GND핀(접지)

피코의 GP26, GP27, GP28핀은 아날로그로 연결해요.

💻 2 프로그래밍 (68쪽)

28번 핀에 연결된 심박 측정 센서의 값(아날로그 값)을 측정하고, 이를 디지털 값으로 변환(ADC)하여 bpm 변수에 저장해요. 코드를 실행하면 현재 심박수를 출력해요. 코드 맨 아래 time.sleep(0.5)가 쉬는 시간을 정해요.

from machine import Pin, ADC          # ADC 클래스(아날로그 센서 제어) 사용
import time

heartbeat_sensor = ADC(Pin(28))        # 28번 핀에 연결된 센서에 대한 ADC 객체 생성

while True:
    heartbeat_value = heartbeat_sensor.read_u16()   # 아날로그 값을 읽음(0~65,535).
    heart_rate = (heartbeat_value / 65535) * 3.3    # 0V ~ 3.3V 범위 내에서 값을 변환
    bpm = (60 / 2) * heart_rate                     # 심박 측정값(분당 심박수)을 계산하여 bpm 변수에 저장
    print('심박동 수치: ', bpm)                     # 현재 심박수 출력

    if bpm < 40 or bpm > 120:                       # 정상 수치와 비정상 수치를 분류해 출력
        print('비정상적인 심박동 수치: ', bpm)
    else:
        print('정상적인 심박동 수치: ', bpm)

    time.sleep(0.5)                                 # 0.5초마다 측정

위 코드는 피코에서 실행하는 코드라서 웹에서는 읽기만 해요. 아래에서 계산 부분만 흉내 내 봐요.

TIP · 아날로그-디지털 변환기(ADC)심박 측정 센서의 출력값(아날로그 값)을 디지털 값으로 변환하려면 아날로그-디지털 변환기(ADC)를 사용해야 해요. 라즈베리파이 피코는 내장된 ADC를 사용해 아날로그 값을 읽어요.
코드 가이드뜻
while True:주어진 조건이 참(True)인 동안 반복적으로 코드 블록을 실행하는 제어 구조예요. while True의 조건은 계속 참이므로 그 안에 있는 코드는 계속 반복해서 실행돼요.
if-else조건에 따라 다른 코드를 실행하도록 하는 조건문이에요. 조건식이 참이면 if의 코드가, 거짓이면 else의 코드가 실행돼요.

🧪 계산 따라 해 보기 · 센서값 → 전압 → bpm

피코가 없어도 괜찮아요. 센서가 읽은 값(read_u16())을 리스트로 미리 적어 두고, for로 하나씩 꺼내 같은 식으로 계산해요. 숫자를 바꿔 실행해 보세요.

값을 바꿔 실행해 보세요. 어떤 값부터 「비정상」이 나오나요? 값을 가장 크게 해 보면(65535) bpm은 얼마가 나오나요?

측정 장치 만들기 · 결과를 확인하려면 먼저 측정 장치를 만들어 몸에 붙여요. 심박 측정 센서 뒤에 벨크로 테이프를 붙이고, LED가 있는 앞면에는 투명 테이프를 한 겹 붙여 준 뒤, 벨크로 테이프로 센서를 측정할 손가락 끝에 묶어 줘요.

프로그램 실행하기 · Run 버튼을 눌러 프로그램을 실행하면, 장치를 부착한 뒤 나의 심박 측정값이 출력돼요.

교과서 말풍선 · 실제 심박 측정기를 활용해 출력값을 비교하고, 오차가 있으면 변수에 값을 계산하여 맞춰 주면 좋아요.

해 보기 · 심박수 측정하기센서를 착용한 상태로 평상시의 심박수와 운동을 하고 난 후의 심박수를 비교해 보자.

🔎 장치 살펴보기 · 심박 측정 센서 (68쪽)

심박 측정 센서는 피지컬 컴퓨팅 마이크로컨트롤러와 함께 사용되어 사용자의 심장 박동을 측정하고 모니터링할 수 있어요. 센서마다 출력값의 범위가 다를 수 있으므로, 센서의 출력 범위를 알려 주는 해당 센서의 데이터 시트를 확인해야 해요. 일반적으로 심박 측정 센서는 0~5V 또는 0~3.3V 범위 내에서 출력값을 제공해요.

실습 2 · 피에조 버저로 경고음 울리기

교과서 69쪽 · 회로 구성, 주파수와 소리 크기

쉽게 말하면피에조 버저는 전기 신호를 받으면 떨려서 소리를 내요. 코드에서는 얼마나 빠르게 떨지(주파수)와 얼마나 크게 울릴지(소리 크기)를 정해 줘요.

🔌 1 회로 구성 (69쪽)

실습 1에서 만든 기기로 나의 심박수를 확인했다면, 피에조 버저로 경고음을 울리는 장치를 만들어 봐요. 피에조 버저와 피코를 아래 회로 연결 방법에 따라 연결해요.

피에조 버저피코
IN(S)GP0핀
VCC(+)3V3핀(전원 공급)
GND(-)GND핀(접지)

피에조 버저의 모듈에 각인된 극성과 회로를 확인하고, 피코의 입출력 핀 중 한 개를 사용하여 두 장치를 연결해요.

💻 2 프로그래밍 (69쪽)

피에조 버저를 제어하는 프로그램을 작성해요.

from machine import Pin, PWM           # PWM 클래스(버저 주파수 영역 설정) 사용
import time

buzzer = PWM(Pin(0))                   # 0번 핀에 연결된 버저에 대한 PWM 객체 생성

while True:                            # 무한 반복 시작
    buzzer.freq(523)                   # 523Hz 음의 주파수 설정
    buzzer.duty_u16(1000)              # 피에조 버저 켜기(경고음 발생)
    time.sleep(1)                      # 1초 대기
    buzzer.duty_u16(0)                 # 피에조 버저 끄기
    time.sleep(1)                      # 1초 대기
코드 가이드뜻
buzzer.freq( )버저가 발생시킬 주파수를 설정해요.
buzzer.duty_u16( )버저의 음량을 설정해요. 설정한 값이 클수록 소리가 커져요.

🔎 장치 살펴보기 · 피에조 버저 (69쪽)

피에조 버저는 전기 신호를 주면 진동이 일어나며, 이 진동이 주파수(단위, Hz)에 의해 공간에서 소리가 되어 출력돼요. 주로 경보기, 게임, 디지털 시계, 컴퓨터 부팅 시 발생하는 비프음 등에 사용돼요. 간단히 회로를 연결하는 것만으로도 쉽게 사용할 수 있어 전자 공학 분야에서는 교육용 장비나 실험에도 활용하고 있어요.

실습 3 · 모니터링 장치 만들기

교과서 70쪽 · 센서와 버저를 합치기

쉽게 말하면실습 1의 심박수 계산과 실습 2의 버저 소리를 하나로 합쳐요. 정상 범위를 벗어났을 때만 0.5초 간격으로 「도」음 경고음이 울리게 해요.

🔌 1 회로 구성 (70쪽)

실습 1과 실습 2를 참고하여 심박수가 일정 범위를 벗어났을 때 0.5초 간격으로 「도」음의 경고음이 울리는 웨어러블 장치를 만들어 봐요. 심박 측정 센서와 버저, 피코를 아래 회로 연결 방법에 따라 연결해요.

심박 측정 센서피코
SGP28핀
+3V3핀
-GND핀
피에조 버저피코
IN(S)GP0핀
VCC(+)3V3핀
GND(-)GND핀
TIP · 브레드 보드 전원단 활용연결할 센서 및 액추에이터가 2개 이상이면 브레드 보드 전원단을 활용할 것을 권장해요. 피코에서 사용 가능한 3V3핀과 GND핀이 개수가 적기 때문에 전원단을 활용하면 다른 부품에 고정된 전원을 공급하여 사용이 가능해요.

💻 2 프로그래밍 (70쪽)

설정한 심박수에서만 경고음이 울리는 프로그램을 작성해요.

from machine import Pin, ADC, PWM
import time

heartbeat_sensor = ADC(Pin(28))        # 28번 핀에 연결된 센서에 대한 ADC 객체 생성
buzzer = PWM(Pin(0))                   # 0번 핀에 연결된 버저에 대한 PWM 객체 생성

while True:                            # 무한 반복 시작
    heartbeat_value = heartbeat_sensor.read_u16()   # 아날로그 값을 읽음(0~65,535).
    heart_rate = (heartbeat_value / 65535) * 3.3    # 0 ~ 3.3V 범위 내에서 값을 변환
    bpm = (60 / 2) * heart_rate                     # 심박 측정값(분당 심박수)

    if bpm < 40 or bpm > 120:                       # 정상 수치보다 낮거나 높을 때
        print('비정상적인 심박동 수치: ', bpm)      # 비정상 수치(심박 측정값) 출력
        buzzer.freq(523)                            # 5 옥타브 '도' 주파수 설정
        buzzer.duty_u16(1000)                       # 피에조 버저 켜기(경고음 발생)
        time.sleep(0.5)                             # 0.5초 대기
        buzzer.duty_u16(0)                          # 피에조 버저 끄기
        time.sleep(0.5)                             # 0.5초 대기

    else:
        print('정상적인 심박동 수치: ', bpm)

실습 1과 달라진 점은 두 가지예요. 첫째, buzzer 객체를 만들었어요. 둘째, if 안(비정상일 때)에서 버저를 켜고 끄는 줄이 늘었어요. else(정상일 때)에서는 수치만 출력해요.

버저는 웹에서 켤 수 없으니, 비정상일 때 print()로 「삐- 경고음」이라고 알려 주는 방식으로 흉내 내요. 센서값 리스트를 바꿔 어떤 값에서 경고음이 나오는지 살펴보세요.

쉽게 말하면피코나 센서가 없어도 컴퓨터 속 가상 회로에서 같은 코드를 실행해 볼 수 있어요. 교과서 71쪽은 WOKWI 시뮬레이터를 쓰는 선택 학습이에요.

1️⃣ 실습 1 · 피에조 버저로 경고음 울리기 (71쪽)

시뮬레이터에서 아래와 같이 버저 회로를 연결하고 프로그램을 작성해 봐요. 시뮬레이터 화면의 + 버튼을 눌러 목록에서 「Buzzer」를 선택해요.

from machine import Pin, PWM
import time

buzzer = PWM(Pin(9))

while True:
    buzzer.freq(523)
    buzzer.duty_u16(1000)
    time.sleep(1)
    buzzer.duty_u16(0)
    time.sleep(1)

빨간 선은 GP9핀, 검은 선은 GND핀에 연결해요. 69쪽의 실습 2 코드와 비교하면 버저가 연결된 핀 번호가 달라요.

2️⃣ 실습 2 · 네오픽셀 LED가 켜질 때마다 멜로디 소리 내기 (71쪽)

시뮬레이터에서 버저와 네오픽셀 LED 회로를 연결하고 프로그램을 작성해 봐요.

도전 과제빈칸을 채워서 네오픽셀 LED가 한 개씩 빨간색으로 켜지면서 버저가 울리고, 모든 LED가 빨간색으로 변할 때 전체 LED가 꺼지는 프로그램을 완성해 보세요!

교과서에는 네오픽셀 개수(16개), 데이터 핀, 버저 핀을 정해 두고 while True: 아래를 빈칸으로 비워 둔 코드가 있어요. 빈칸 채우기는 시뮬레이터에서 직접 해 봐요. 앞에서 배운 네오픽셀 코드(57쪽)와 버저 코드(69쪽)가 힌트가 돼요.

마무리

오늘 정리 · 생각 정리 · 질문폼

심박 측정 센서의 값(0~65535)을 전압 → bpm으로 바꾸고, 일반적인 성인의 정상 범위인 40~120bpm를 벗어나는지 조건문(if-else)으로 나눠요.
피에조 버저는 주파수(freq)로 소리의 높이를, duty_u16 값으로 소리의 크기를 정해요. 값이 클수록 소리가 커져요.
센서와 버저를 합치면, 비정상일 때만 경고음이 울리는 웨어러블 모니터링 장치가 돼요. 이런 기기를 개발하는 사람이 스마트 헬스케어 기기 개발자예요.
