## 커스텀 체험 · 「감정 전염 시뮬레이션」(03)
교과서 150~152쪽 넷로고 코드를 그대로 흉내 낸 것(규칙 출처 = 인쇄된 코드):
- 33×33 패치, 가장자리 이어짐(wrap). 좌표는 −16.5~16.5 실수, 패치 = floor(좌표+16.5)(넷로고 `round`와 같음).
- `setup`: number명(슬라이더 0~100, 기본 10) 회색, 무작위 위치·방향. `joy`: humans 중 한 명 노랑. `me`: 가운데(0,0)에 users 1명(크기는 02에서 고른 값, 없으면 3, 방향 무작위, 최대 5명). `thanks`: users 빨강. `move`: 방향(0·90·180·270)을 정하고 2칸 이동(W/A/S/D 키는 이 화면이 보일 때만).
- `go`: humans만 자기 방향으로 `random 속도`칸(속도 = 02에서 고른 값, 없으면 5 → 0~4칸). 그다음 모든 터틀을 **무작위 순서로 하나씩**(넷로고 `ask`와 같음) 같은 패치의 다른 터틀 중 노랑이 있으면 노랑, 빨강이 있으면 빨강(순서대로 확인, 바뀐 색은 뒤 터틀에게 바로 보임). tick +1.
- 「노란색 수용 정도」 100%/30%는 153쪽 심화(`and random-float 1 < 0.3`)로, **노랑 규칙에만** 적용(교과서 표가 노랑 줄만 보여 줌). 빨강은 항상 100%.
- 버튼: go 1틱·go 10틱·▶ 자동(최대 300틱, 모두 같은 색이 되면 멈춤)·멈춤. 자동 실행은 화면을 떠나면(MutationObserver) 정지, 속도(보통 110ms/느리게 330ms). 모니터 틱·즐거움(노랑 수)·고마움(빨강 수)은 교과서 플롯·모니터처럼 터틀 색 개수(‘나’ 포함).
- 「이 실행 기록하기」 표는 비교용 보조 기능(교과서에 없음, 저장 안 함).
- 처음 실행하면 number 10은 300틱 안에 거의 퍼지지 않고 100은 100틱 안팎에 모두 퍼짐(제작자가 파이썬으로 100회 안팎 확인). 교과서가 직접 말하는 결론은 아니고 학생이 관찰·해석하도록 둠.

## pyrun 목록
- **anRun1**(03): 위 규칙의 파이썬 흉내(`NUMBER=10`, `TICKS=300`, 30틱마다 노란 사람 수, 모두 노랑이 되면 틱 출력). 사람 수를 100으로 바꿔 비교. 로컬 `python3 -I` 확인(0.02초).
- **anRun2**(03): `accept`(100%·30%)를 바꿔 같은 실험(NUMBER=100)을 두 번 실행해 모두 노랑이 된 틱을 비교. 확인 완료(0.03초). 두 코드 모두 `while True`·`input`·`sleep`·파일 읽기 없음.

## 선생님 확인할 점
- **교과서와 다르게/추가로 만든 것**: 실행 기록표, 자동 실행 속도 버튼, 02의 크기·속도 칩이 03 체험에 적용되는 연결, 실행 순서 ✓ 표시, `sorter` 문장 9개(교과서 문항 아님, 코드 설명에서 만듦), 터틀 나무 SVG(151쪽 TIP 그림을 다시 그림).
- **흉내 모델 규칙 출처**: 교과서 150~152쪽 인쇄 코드 + `152쪽_모델구현명령어.txt`. 교과서에 없는 규칙은 넣지 않음(‘나’는 한가운데에 생기고 방향이 무작위인 것은 넷로고 `create-users`의 기본 동작).
- **150~151쪽 코드의 `set size 3`**은 교과서에 그대로 인쇄돼 있고, 152쪽 해 보기에서는 같은 자리가 빈칸 `▢`. 01 코드 카드는 150~151쪽 그대로(3), 02는 빈칸으로 표시함. `forward random 5`도 마찬가지.
- 152쪽 의사 코드의 줄바꿈·들여쓰기는 그림 그대로가 아니라 읽기 쉽게 정리함(내용은 같음). 03 pyrun의 비율은 난수라 실행마다 달라짐을 화면에 안내.
- 154쪽 사례 적용 「예1·예2」와 기능 확장 「예 소문, 유언비어 확산 시뮬레이션」은 학생용 PDF에 인쇄된 문구. 「나의 생각」 칸은 메모로만 둠(교사용 예시 답은 넣지 않음).
- 155쪽 직업 설명은 학생용 PDF 인쇄문을 줄여 다시 씀(사진 생략).
- 넷로고 색 이름 안내는 교과서에 없는 한 줄(‘영어 색 이름’) — 넷로고 기본 색 이름을 쓴다는 일반 사실. 불필요하면 빼도 됨.
