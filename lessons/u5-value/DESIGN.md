## pyrun 목록
- **vlRun** (01): 앱인벤터 「숫자 인식 함수」 블록을 흉내 낸 `숫자_찾기(문장)`(`split()`→`isdigit()`→리스트)에 연습용 문장 5개를 넣어 「통과 / 다시 말하기」를 출력. 17줄, `input()`·반복 제한 없음, `for`는 정해진 리스트만. 로컬 `python3 -I`로 실행 확인.

## 확인할 점
- **pyrun은 제작자가 만든 흉내**: 교과서에는 숫자 인식 함수 블록의 안쪽과 테스트 케이스 표가 없음. 문장 5개와 「통과/다시 말하기」 출력은 내가 정한 연습용이고, 함수는 아라비아 숫자만 찾음(한글 「일·삼」은 못 찾음). 194쪽 말풍선(「일, 이, 삼」 같은 짧은 말은 음성 인식이 잘 안 됨)과 같은 주제지만 원리는 다름(음성 인식 대 문자열 검사) → 화면에 「한글로 쓴 숫자는 못 찾아요」 안내를 적어 둠.
- **sorter 「몇 번째 순서」**: 공용 `sorter`가 분류 방식이라 ❶❷❸(❶~❻) 단추로 순서를 고르게 함. 설치 단계 ❸ 「아래와 같은 창이 뜨면」는 그림을 가리키므로 「창이 뜨면 [설정]을 누른다」로 줄임.
- **196쪽 완성 화면**: 사진 대신 색 상자 모형. 인쇄된 앱 이름(소문난 햄버거 맛집)과 메뉴 이름(치즈·새우·치킨 버거)은 placeholder로만 씀. 컴포넌트 속성 표는 u5-build 차시 몫이라 이름만 안내.
- **가치 성찰(197쪽)**: 교과서 인쇄 기준·점수 안내(10/5/1점)를 그대로 옮김. 합계는 「슬라이더를 움직인 칸」만 더함(처음 5점 표시 때문에 생기는 착시 방지) — 교과서에는 합계 칸이 없어 내가 더한 기능.
- **198쪽 돌아보기**: 교과서는 평가자 기준 질문 + 5점 점수(합계 칸)인데, 점수·합계는 빼고 질문을 「~했어요」 문장으로 바꿔 고르는 `chips`로 함. 기준 질문의 표현이 달라졌으니 대조 필요.
- **199쪽 직업 카드**: 학생용 PDF 인쇄문을 해요체로 줄여 씀. 「필요 역량」 낱말은 인쇄 그대로.
- 마무리 퀴즈 둘째 문항(「글자 읽어주기」 기본 엔진)은 194쪽 그림 속 글자(「기본 엔진(Google 음성 인식 및 합성)」)에 근거.
- 스마트폰 화면 캡처는 쓰지 않았으므로 설정·설치 화면의 모양은 학생이 직접 폰에서 확인.
- 질문폼 `sw-u5-value`는 `tools/gen_forms.py`·`course.json`에 등록 필요(이 차시 작업에서는 건드리지 않음).
