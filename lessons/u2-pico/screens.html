🔧 실습 환경 설정 세 단계 (54~55쪽)

1
펌웨어 설치하기
  1. 검색창에서 「마이크로파이썬(MicroPython)」을 검색해 홈페이지(micropython.org)의 다운로드 메뉴로 가요. 「pico」를 입력하고 라즈베리파이 피코 그림을 찾아 눌러, 최신 펌웨어 파일(.uf2)을 내려받아요.
  2. 피코 위쪽의 BOOTSEL 버튼을 누른 상태에서 USB로 컴퓨터와 피코를 연결해요. 컴퓨터가 RPI-RP2 장치로 알아봐요.
  3. 드라이브가 오른쪽 그림처럼 보이면, 내려받은 uf2 파일을 RPI-RP2 드라이브에 복사해 붙여 넣거나 끌어 놓아요. 장치가 새로 연결되면서 RPI-RP2 장치가 사라지면 설치가 끝난 거예요.
2
통합 개발 환경(IDE) 설치하기
  1. 검색창에 영문으로 「Thonny」를 입력해 홈페이지로 가요. 내 운영체제에 맞는 파일을 내려받아 순서대로 설치해요.
  2. 설치한 뒤 도구(Tools) 메뉴에서 옵션(options)을 열어요. 인터프리터(Interpreter) 탭에서 MicroPython (Raspberry Pi Pico)를 고르고, 통신 포트는 직렬 장치 포트 번호로 골라요.

포트 번호 찾는 법(교과서 말풍선): 모니터 화면 왼쪽 아래의 윈도 버튼을 오른쪽 클릭해 나오는 메뉴에서 장치 관리자 → 포트(COM & LPT)를 열어 Serial Port의 번호를 확인해요.

3
라이브러리 설치하기
  1. 57~58쪽 실습을 위해 neopixel과 dht 라이브러리를 설치해요.
  2. Thonny의 Tools → Manage packages를 눌러요. 검색칸에 이름(neopixel, dht)을 쓰고 검색한 뒤, 나온 결과를 눌러 설치해요.

💡 TIP · 라이브러리를 설정하는 이유 라이브러리는 이미 구현된 기능을 제공하므로, 이를 활용하면 코드를 빠르게 작성할 수 있어요. 파이썬은 풍부한 표준 라이브러리를 제공하지만, 특정 작업이나 기능을 하려면 추가 라이브러리가 필요해요.

실습 1 · 피코 내장 LED 제어하기

교과서 56쪽 · 회로 구성, 프로그래밍, 실행 결과

쉽게 말하면피코 보드 위에는 작은 LED가 이미 붙어 있어요. 이 LED를 켜고(1), 1초 기다리고, 끄고(0), 1초 기다리는 일을 계속 반복하면 불빛이 1초 간격으로 깜빡여요.

1️⃣ 회로 구성 (56쪽)

브레드 보드에 피코를 연결하고, 내장된 LED를 쓰기 위해 25번 핀을 찾아봐요. 내장 LED를 제어하는 핀은 보드 상단의 LED(GP25핀)에 연결되어 있어요. 따로 부품을 달지 않아도 돼요.

2️⃣ 프로그래밍 · 읽는 코드 (56쪽)

피코에 내장된 LED를 제어하는 프로그램이에요. 피코에서만 돌아가서 여기서는 읽기만 해요.

from machine import Pin           # machine 모듈에서 Pin 클래스(핀 제어) 사용
import time                       # 시간 지연 기능을 위한 time 모듈 사용
led = Pin(25, Pin.OUT)            # 25번 핀을 출력 모드로 led 객체 생성

while True:                       # 무한 반복 시작
    led.value(1)                  # LED 켜기
    time.sleep(1)                 # 1초 대기
    led.value(0)                  # LED 끄기
    time.sleep(1)                 # 1초 대기

코드 가이드 카드를 눌러 확인해요.

3️⃣ 실행 결과 (56쪽)

Thonny의 Run 버튼을 눌러 프로그램을 실행해요. 1초 간격으로 피코에 내장된 LED의 불빛이 깜빡이는 것을 확인할 수 있어요.

▶ 해 보기 · 깜빡임 순서를 파이썬으로 흉내 내 보기

피코 코드의 while True는 끝없이 도는 반복이라 웹에서는 돌릴 수 없어요. 그래서 3번만 도는 for로 바꾸고, 켜고 끄는 일을 print( )로 보여 줘요. 반복 횟수 3이나 출력 글을 바꿔서 다시 실행해 봐요.

실습 2 · 네오픽셀 LED 제어하기

교과서 57쪽 · 회로 구성, RGB 값, 해 보기

쉽게 말하면네오픽셀은 작은 LED가 줄줄이 붙어 있어서 LED마다 따로 색을 정할 수 있는 부품이에요. 색은 빨강(R)·초록(G)·파랑(B)을 각각 0~255로 섞어서 만들어요. (255, 0, 0)은 빨강만 가득 켠 빨간색이에요.

1️⃣ 회로 구성 (57쪽)

네오픽셀 3핀의 글씨를 잘 보고, 브레드 보드를 이용해 아래 표처럼 연결해요.

네오픽셀피코
GNDGND핀(접지)
DIGP0핀(디지털 연결)
5V3V3핀(전원 공급 VCC)

2️⃣ 프로그래밍 · 읽는 코드 (57쪽)

from machine import Pin
import time
from neopixel import NeoPixel      # 네오픽셀 사용을 위한 모듈 호출

NUM_LEDS = 4                       # 사용할 LED 개수
PIN_NUM = 0                        # DIN 핀으로 사용할 입출력(GPIO) 핀 번호

pixels = NeoPixel(Pin(PIN_NUM), NUM_LEDS, bpp = 3)   # RGB 모드(bpp=3)를 사용해 NeoPixel 객체 생성

while True:
    pixels.fill((255, 0, 0))       # 빨간색(R, G, B)으로 LED 켜기
    pixels.write()                 # 변경 사항 적용
    time.sleep(1)                  # 1초 대기
    pixels.fill((0, 0, 0))         # 모든 LED 끄기
    pixels.write()                 # 변경 사항 적용
    time.sleep(1)                  # 1초 대기

코드 가이드 카드를 눌러 확인해요.

🎨 코드 가이드 · pixels.fill((255, 0, 0)) 괄호 안 숫자는 R, G, B 값이에요. 원하는 색의 RGB 값은 「색상 팔레트」를 검색하면 확인할 수 있어요.

🎚️ 체험 · R, G, B를 섞어 색 만들기

막대를 움직여 세 값을 바꿔 봐요. 아래 색 칸과 코드 줄이 같이 바뀌어요. (255, 0, 0)과 (0, 0, 0)은 어떤 색인지도 확인해 봐요.

(255, 0, 0)
pixels.fill((255, 0, 0))

모니터 화면의 색 미리보기예요. 실제 네오픽셀의 밝기와 색은 조금 다르게 보일 수 있어요.

3️⃣ 실행 결과 (57쪽)

Run 버튼을 눌러 실행하면 네오픽셀의 빨간색 불빛이 1초 간격으로 깜빡이는 것을 확인할 수 있어요.

▶ 색 이름을 (R, G, B) 튜플로 바꿔 보기

색 이름과 RGB 튜플을 딕셔너리에 짝지어 두고, for로 하나씩 꺼내 fill 줄을 만들어 보여 줘요. 색 이름과 값을 바꾸거나 새로 넣어 봐요.

노랑·흰색의 값은 교과서에 없는 예예요. 위 슬라이더로 확인해 봐도 좋아요.

✍️ 해 보기 · LED 제어 프로그램 구현하기 (57쪽)

1초 간격으로 네오픽셀 LED의 색이 빨강, 파랑, 초록 순서로 바뀌는 프로그램을 작성해 보세요. 아래 칸의 ___ 자리에 색(R, G, B 튜플)을 직접 채워서 실행해 봐요.

⚠️ ___를 채우기 전에는 오류가 나는 게 정상이에요. 슬라이더에서 빨강·파랑·초록이 되는 값을 찾아 보고, 순서대로 채워 봐요. 피코에서는 같은 색 목록을 pixels.fill(색), pixels.write(), time.sleep(1)과 함께 반복하면 돼요.

피코에는 온도 센서가 내장되어 있지만, 이번 실습에서는 피코에 온습도 센서를 따로 연결해 써요. 온습도 센서 모듈에 새겨진 극성과 회로를 확인하고, 피코의 입출력 핀 한 개를 써서 두 장치를 연결해요.

2️⃣ 프로그래밍 · 읽는 코드 (58쪽)

코드 해설 dht 라이브러리를 불러와 dht 핀 연결로 sensor.measure() 함수를 호출해 데이터를 측정한 뒤, sensor.temperature() 함수와 sensor.humidity() 함수로 온도와 습도를 읽어요. 이 값을 출력창에 출력하고, time.sleep(1)로 측정 간격을 1초로 정해요.

from machine import Pin
import time
import dht                         # 온습도 센서 모듈 설치

sensor = dht.DHT11(Pin(22))        # 22번 핀에 연결된 DHT11 센서 초기화

while True:
    sensor.measure()               # 센서에서 측정 시작
    temp = sensor.temperature()    # 온도 측정
    hum = sensor.humidity()        # 습도 측정

    print('Temperature: ', temp, ' °C')   # 온도와 습도 출력
    print('Humidity: ', hum, ' %')
    time.sleep(1)                  # 1초마다 측정

코드 가이드 카드를 눌러 확인해요.

교과서 말풍선: 이 코드를 실행하면 온습도 값을 피코에서 출력할 수 있어요. 이를 활용해 환경 모니터링, 자동 제어 같은 다양한 응용 프로그램을 개발할 수 있어요.

from machine import Pin
import neopixel
import time

NUM_PIXELS = 16
PIN_NUM = 0
pixels = neopixel.NeoPixel(Pin(PIN_NUM), NUM_PIXELS)

while True:
    for i in range(NUM_PIXELS):
        pixels[i] = (255, 0, 0)   # LED를 빨간색으로 변경
        pixels.write()
        time.sleep(0.5)

    for i in range(NUM_PIXELS):
        pixels[i] = (0, 0, 0)     # LED를 꺼짐 상태로 변경
        pixels.write()
        time.sleep(0.5)

피코 실습은 펌웨어 설치 → 통합 개발 환경(토니) 설치 → 라이브러리(neopixel, dht) 설치로 준비하고, 코드는 py 파일로 저장해야 연결하거나 외부 전원을 켰을 때도 계속 작동한다.
내장 LED(GP25핀)는 led.value(1)로 켜고 led.value(0)으로 끈다. 네오픽셀은 pixels.fill((R, G, B))로 색을 정하고 pixels.write()로 적용하며, 온습도 센서(DHT11)는 measure() 뒤에 temperature()·humidity()로 값을 읽는다.
센서가 읽은 온도를 조건문(if·elif·else)으로 가르고 범위마다 다른 (R, G, B) 색을 정하면, 온도에 따라 색이 변하는 미디어 아트 작품을 만들 수 있다.
