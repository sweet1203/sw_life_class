퀴즈 11문항, pyrun 1개(로컬 python3 실행 확인). 화재 흉내 규칙 로직은 node로 밀도별 확인(밀도 30%·50%·60%·70% 평균 탄 비율 약 10·26·64·95%). 375px 가로 넘침 없음, 화면 이동·버튼 동작 오류 없음(헤드리스 크롬 확인). 자동 재생은 최대 200틱·화면을 떠나면 정지.

**선생님 확인할 점**
- 화재 흉내 규칙(왼쪽 열 점화, 상하좌우 전파, 탄 칸은 재, 탄 비율=옮겨 붙은 나무/처음 나무)은 넷로고 기본 Fire 모델을 본뜬 것으로 제작자가 정함. 바람 등 Extension 3 기능은 없음(화면에 밝힘). 슬라이더 범위 30~100%는 연습용.
- 근육 발달 화면 모형은 135쪽 그림을 보고 직접 그린 모형(슬라이더 값 95·8·5·50, 틱 143은 인쇄된 값, 원·그래프 모양은 꾸밈). 근육 발달 결과 실행은 만들지 않고 QR 안내.
- 시나리오 점검기의 슬라이더 범위(강도 0~100, 수면 0~12시간, 운동 사이 1~10일)와 시작값은 연습용. 교과서·PPT 예시 값은 쓰지 않음. 결과(그래프)는 만들지 않고 「다른 값 개수」만 셈.
- 137쪽 코드 해설 카드의 breed·-own·패치 설명과 `;;`(주석) 설명은 넷로고 일반 지식으로 제작자가 씀. anabolic/catabolic 설명은 코드 주석(muscle building/breaking down) 번역.
- 화재 모델의 목적·구현 기능 칸은 교과서 빈칸이라 메모만(PPT의 예시 답은 넣지 않음). 퀴즈의 숲 흉내 문항은 이 차시 흉내 규칙에서 냄.
- 인터뷰는 4개 질문을 줄여 옮김. 사진 없음. 성취도 점검 문장·보충하기 쪽은 138쪽 인쇄본 그대로.
