pyrun 2개, 퀴즈 15문항.
- pyrun 1: 문장 4개를 `split()`·`isdigit()`로 나눠 숫자만 리스트에 담아 출력(숫자 없는 문장은 빈 리스트). 로컬 확인: `['2']`·`['3']`·`[]`·`['5','1']`.
- pyrun 2: 정해 둔 주문 3개를 `for`로 돌며 종류·수량으로 금액 계산. 총금액 줄은 `총금액 = 메뉴1 + ___`(빈칸). 채우기 전 `NameError` 확인, 빈칸을 채웠을 때 도는 것까지만 확인하고 채운 코드는 넣지 않음. 화면에 「채우기 전에는 NameError가 나는 게 정상」 안내.

**확인할 점**
- 블록은 모두 읽기용 `<pre class="code">`로 교과서 PDF 인쇄 글자를 옮기고 끼움은 들여쓰기로 표현했다(블록 모양·색은 없음). 192쪽의 「아니고 만약 종류 = 2·3」과 합치기 안의 `메뉴1 + ▢`(노란 상자)는 교과서처럼 비워 두었다. 191쪽 메뉴2·3 버튼 블록도 빈 블록으로 둠. 해 보기 정답 블록은 어디에도 없다.
- pyrun 2는 파이썬 문법상 메뉴 2·3 단가 분기(`elif`)를 넣어야 돌아가서 넣었다(앱인벤터 노란 상자의 정답 블록은 아니지만 구조가 비슷함). 빈칸은 총금액 줄 하나뿐. 메뉴2 6000·메뉴3 7000은 제작자가 정한 연습용 값(코드 주석·화면에 「연습용」 표시). 메뉴1 5000만 192쪽 값.
- 190쪽은 변수 메뉴1~3을 「각 주문 메뉴의 수량을 저장」한다고 쓰지만, 192쪽 블록은 같은 변수에 `5000 × 주문수량`(금액)을 넣는다. 교과서 문장 그대로 표에 두고, 192쪽에서 금액이 들어간다는 안내 한 줄만 덧붙였다. 원본 확인 필요.
- 192쪽 해 보기 ❶의 노란 상자 지시와 TIP(「메뉴 2, 메뉴 3의 값을 가져와 더하면 된다」)는 교과서에 인쇄된 문장이라 TIP으로 실었다. 이 문장 때문에 pyrun 2 빈칸의 힌트(「메뉴2와 메뉴3 값을 더해 보세요」)가 정답에 가깝다. 더 숨기려면 힌트 주석을 지우면 된다.
- 191쪽 숫자 함수 블록은 해 보기에서 학생이 직접 조립하라고 하면서 같은 쪽에 완성 그림이 인쇄되어 있어, 완성 블록을 읽기 카드로 실었다(설계안 지시). 메모 칸은 「막힌 곳」을 적게 함.
- 이미지를 글·도형으로 옮긴 곳: 186쪽 앱인벤터 화면 캡처 → 7칸 SVG 모형(제작자 그림), 188~189쪽 화면 캡처 → 설명 글, 자료 8 컴포넌트 구성 → 칸별 `<pre>` 트리(간격 레이블 3개는 따로 칸으로 둠), 187쪽·196쪽 완성 화면 사진 → 단순 휴대폰 모형(메뉴 이름은 「메뉴1」, 앱 이름은 「(앱 이름)」). `188쪽_메뉴이미지`, `181쪽_kiosk.aia`, 참고 영상은 쓰지 않음.
- 196쪽 속성 표는 높이·너비·글꼴 크기 위주로 11줄로 줄였다(배경색·정렬 일부 포함). 「메뉴N 주문」 글자(빨간 글씨)는 제작자 요약으로 「메뉴N 주문」이라 적음.
