준비 학습 · 개발 도구 살펴보기

교과서 186쪽 · 앱인벤터 실행과 화면 구성

쉽게 말하면앱인벤터는 블록을 끌어다 놓아 앱을 만드는 도구예요. 인터넷 사이트에 들어가서 바로 쓸 수 있고, 중학교 때 배운 엔트리·스크래치와 사용 방법이 비슷해요.

🧰 앱인벤터란? (186쪽)

앱인벤터는 안드로이드 기반 스마트 기기나 에뮬레이터(대리 실행기)를 이용해 앱을 만들 수 있도록 해 주는 개발 도구예요. 웹상에서 개발 환경을 제공하기 때문에 사이트에 접속해서 프로그래밍할 수 있어요. 드래그 앤 드롭 방식이라서 앱을 만들려는 의지만 있다면 누구든 간단히 개발할 수 있도록 지원해요.

1
실행하기앱인벤터 사이트(appinventor.mit.edu)에 접속하고, 왼쪽 상단의 [Create Apps!]를 누른 뒤 구글 계정으로 로그인해요.
2
프로젝트 생성하기프로그램 창이 열리면 상단 맨 오른쪽 계정 옆의 언어 메뉴에서 「한국어」를 선택해요. 그다음 상단 메뉴에서 [New project]를 누르고 프로젝트명을 정해요.

03

(1) 화면 개발

교과서 188~189쪽 · 컴포넌트 구성과 속성

쉽게 말하면화면은 상자(배치) 안에 부품(버튼·레이블)을 넣는 식으로 만들어요. 큰 상자 안에 작은 상자를 넣고, 그 안에 글자 칸을 넣어요.

📱 화면 개발 5단계 (188~189쪽)

앱을 실행했을 때 주문할 수 있는 메뉴 버튼이 나오고, 음식의 수량을 말하면 음성을 인식해 금액을 표시하는 동시에 음성으로 알려 주는 화면을 개발해 봐요.

1
메인 화면 설정 및 제목 넣기컴포넌트의 Screen1 속성에서 수평정렬을 「가운데:3」으로 설정해요. 레이블을 뷰어로 끌어다 놓고 이름 바꾸기에서 제목이라고 입력해요.
2
메뉴 버튼 만들기제목 아래에 메뉴 버튼이 가로로 나열되도록 레이아웃의 스크롤가능수평배치를 가져와 높이를 정하고(35퍼센트), 그 안에 버튼을 세 개 넣어요. 버튼 모양을 만든 뒤, 미디어에 이미지를 올려 버튼의 이미지 속성으로 골라요.
3
메뉴 주문 확인 창 만들기수직배치 안에 수평배치를 넣고, 그 안에 레이블 3개를 넣어요. 완성된 수평배치를 메뉴 개수만큼 늘려요(주문 내역이 가로로, 메뉴는 세로로 정렬돼요).
4
총 금액 만들기주문 내역 아래에 수평배치를 놓고 너비를 넓힌 뒤 레이블 2개를 넣어요.
5
종료 버튼 및 음성 인식 요소 만들기버튼을 끌어다 놓고, 미디어의 음성 변환·음성 인식, 사용자 인터페이스의 알림을 뷰어로 끌어다 놓아요. 이 셋은 앱 화면에는 나타나지 않으나 기능은 쓸 수 있는 보이지 않는 컴포넌트예요.

💡 TIP · 간격 만들기 4와 5 사이에 여유 간격이 생기도록 사용자 인터페이스에서 레이블을 추가해요. 3과 4 사이, 2와 3 사이에도 같은 방법으로 간격을 추가해요.

(2) 기능 개발 ① 환영 인사 · ② 변수

교과서 190쪽 · 첫 블록과 변수 만들기

쉽게 말하면화면을 다 만들었으면 이제 동작을 넣어요. 앱이 켜지면 말로 인사하게 하고, 주문 내용을 담아 둘 변수(저장 상자)를 미리 만들어요.

🔁 디자이너 화면 ↔ 블록 화면 (190쪽)

표현하고자 하는 화면을 모두 구성한 뒤, 각 요소들이 제대로 기능할 수 있도록 소프트웨어 명령어를 입력해 봐요. 음성 인식 키오스크 앱은 하나의 화면에서 모든 기능이 구현되기 때문에 명령어 블록을 모두 하나의 화면에 구성해요. 디자이너 화면에서 블록 화면으로의 전환은 메뉴 오른쪽 [디자이너], [블록] 버튼을 눌러서 해요.

👋 ① 환영 인사 설정하기 (190쪽, 읽는 블록)

사용자가 키오스크를 쓰려고 앱을 실행할 때 음성으로 들려줄 환영 인사를 설정해요.

언제 Screen1.초기화되었을때
실행  호출 음성변환1.말하기
          메시지  합치기  "저희 매장을 방문해주셔서 감사합니다."
                        "메뉴 1번은 왼쪽 상단"
                        "메뉴 2번은 중앙 상단"
                        "메뉴 3번은 오른쪽 상단을"
                        "터치해주세요"

공통 블록의 텍스트 > 「합치기」 블록은 톱니바퀴를 눌러 문자열을 드래그 앤 드롭으로 추가할 수 있어요. 하나의 텍스트에 모두 작성하는 것도 가능해요.

🎮 블록을 조립하는 순서 교과서의 ❶~❹ 설명을 보고 몇 번째인지 골라요.

📦 ② 변수 만들기 (190쪽)

주문 메뉴 음성 인식 후 음성 안에 섞여 있는 숫자를 담아낼 숫자 리스트 변수, 선택한 메뉴의 종류, 그리고 각 주문 메뉴의 수량을 저장하기 위한 변수를 만들어요. 모든 블록은 「공통 블록」에서 가져와요.

변수 이름처음 값쓰임
숫자리스트빈 리스트 만들기음성 속 숫자를 담아요.
종류빈 텍스트(" ")선택한 메뉴의 종류를 담아요.

(2) 기능 개발 ③ 주문 메뉴 인식 · ④ 숫자 인식 함수

교과서 191쪽 · 버튼 블록과 숫자가져오기 함수

쉽게 말하면메뉴 버튼을 누르면 수량을 말해 달라고 안내하고 듣기를 시작해요. 그리고 사용자가 말한 문장에서 숫자만 뽑아내는 함수를 만들어요.

🍔 ③ 주문 메뉴 인식하기 (191쪽, 읽는 블록)

주문 메뉴를 눌렀을 때 「주문 수량을 말씀해주세요.」라는 안내 메시지가 나오고 음성 인식이 시작돼요. 주문 메뉴를 저장하기 위해 전역 변수 종류의 값을 지정해요.

언제 메뉴1_주문버튼.클릭했을때
실행  호출 음성변환1.말하기
          메시지  "메뉴1 주문 수량을 말씀해주세요."
      호출 음성인식1.텍스트가져오기
      지정하기 전역변수 종류  값  "1"

언제 메뉴2_주문버튼.클릭했을때
실행  (해 보기에서 채워요)

언제 메뉴3_주문버튼.클릭했을때
실행  (해 보기에서 채워요)
  1. 메뉴1_주문버튼 > 「언제 메뉴1_주문버튼.클릭했을때」 블록을 뷰어로 드래그해요.
  2. 음성변환1 > 「호출 음성변환1.말하기」 블록을 뷰어로 드래그해 메뉴1_주문버튼 블록 안에 결합해요.
  3. 공통 블록 > 텍스트 블록을 「음성변환1」 블록의 메시지에 연결하고, 안내 메시지를 입력해요.
  4. 음성인식1 > 「호출 음성인식1.텍스트가져오기」 블록을 「음성변환1」 블록 아래에 결합해요.
  5. 공통 블록 > 변수 > 「지정하기」 블록을 「음성인식1」 블록 아래에 결합하고, ▼를 눌러 「전역변수 종류」를 선택해요.
  6. 공통 블록 > 텍스트 블록을 「지정하기」 블록 값 뒤에 연결하고 숫자 1을 입력해요.

「종류」 변수는 어떤 메뉴를 선택했는지 구분하기 위한 것이므로, 메뉴를 선택했을 때 같은 값을 가지지 않도록 해야 해요.

🔢 ④ 숫자 인식 함수 만들기 (191쪽, 읽는 블록)

주문 메뉴에 대한 음성 인식이 끝난 후 음성에 포함된 숫자만 발췌하는 숫자 인식 함수를 만들어요. 이 함수로 사용자가 말한 문장 속에서 숫자를 인식할 수 있어요.

함수 만들기 숫자가져오기  (인식문장)
실행  지정하기 전역변수 숫자리스트  값  빈 리스트 만들기
      각각 반복 음절  리스트  빈 칸으로 분할하기  가져오기 인식문장
      실행  만약  숫자인가요?  가져오기 음절
            이라면 실행  항목 추가하기  리스트  가져오기 전역변수 숫자리스트
                                      item  가져오기 음절

제어 블록의 「각각 반복」을 가져오면 이 부분이 「항목」으로 설정되어 있는데, 「음절」로 바꿔서 써요.

TIP · 인식할 문장 넣기 함수 블록에서 「함수 만들기」를 가져오면 인식할 문장을 입력할 수 있는 공간이 없어요. ① 톱니바퀴를 눌러요 → ② 「입력」을 끌어와요 → ③ 「x」를 「인식문장」으로 바꿔요.

▶ 해 보기 · 숫자 인식 함수를 파이썬으로 흉내 내기

블록이 하는 일을 같은 순서로 파이썬으로 옮겼어요. 문장을 빈칸으로 나누고(split), 나뉜 낱말마다 숫자인지 확인해(isdigit) 숫자면 리스트에 추가해요. 코드 안 문장을 바꿔 보고, 숫자가 없는 문장일 때 리스트가 어떻게 되는지 확인해 봐요. (실제 앱에서는 사용자가 말한 문장이 들어와요.)

(2) 기능 개발 ⑤ 음성 인식 후 총 금액 안내하기

교과서 192쪽 · 숫자 확인, 금액 계산, 음성 안내

쉽게 말하면말한 내용에 숫자가 있으면 메뉴 가격과 곱해 총 금액을 계산해 말해 주고, 숫자가 없으면 다시 말해 달라고 해요.

💰 ⑤ 음성 인식 후 총 금액 안내하기 (192쪽, 읽는 블록)

음성 주문에 포함된 숫자만을 발췌해 인식된 메뉴의 수량과 입력된 금액으로 총 금액을 계산하고, 이를 다시 음성으로 안내해요. 인식이 제대로 되지 않았을 때는 인식하지 못했다는 메시지가 나오도록 설정해요. (___로 비운 곳은 〈해 보기〉에서 채우는 부분이에요.)

언제 음성인식1.텍스트가져온후  (결과, partial)
실행  함수 호출하기 숫자가져오기  인식문장  가져오기 결과          # ❶
      만약  길이 구하기 리스트 (가져오기 전역변수 숫자리스트)  ≠  0   # ❷
      이라면 실행
          만약  가져오기 전역변수 종류  =  "1"                    # ❸
          이라면 실행
              지정하기 메뉴1_주문수량.텍스트  값
                  항목 선택하기  리스트 (가져오기 전역변수 숫자리스트)  위치 1
              지정하기 메뉴1_주문금액.텍스트  값
                  5000  ×  메뉴1_주문수량.텍스트
              지정하기 전역변수 메뉴1  값
                  5000  ×  메뉴1_주문수량.텍스트
          아니고 만약  가져오기 전역변수 종류  =  "2"
          이라면 실행  ___                                      # 노란 상자
          아니고 만약  가져오기 전역변수 종류  =  "3"
          이라면 실행  ___                                      # 노란 상자
          지정하기 총금액_계산.텍스트  값
              합치기  ( 가져오기 전역변수 메뉴1  +  ___ )   "원"   # 노란 상자
          호출 음성변환1.말하기
              메시지  총금액_계산.텍스트                              # ❹
      아니라면
          호출 음성변환1.말하기
              메시지  합치기  "무슨 말인지 "
                              "잘 모르겠습니다."
                              "다시 말씀해주세요."             # ❺
1
음성 인식이 끝난 후 인식한 음성 속에서 숫자가 포함되어 있는지 확인하는 함수를 호출한다.
2
숫자 가져오기 함수에서 음성 속에 숫자가 있으면 숫자 가져오기 함수로 리스트에 추가하기 때문에, 0과 같지 않으면 숫자를 인식한 것이다.
3
메뉴 버튼이 활성화되었을 때 어떤 메뉴를 선택했는지 변수(종류) 값을 지정해 두었다. 변경된 변숫값을 통해 인식한 주문 수량과 미리 입력된 금액으로 총 금액을 계산하여 화면에 표시한다.
4
계산된 총 금액을 스피커를 통해 음성으로 안내한다.
5
음성 인식이 제대로 되지 않았을 때에 「무슨 말인지 잘 모르겠습니다. 다시 말씀해주세요.」라고 말하게 한다.

TIP 공통 블록에 없는 블록은 공통 블록 바로 아래에 이어진 해당 요소(명령어 다음 첫 번째 칸의 명칭 참조)를 클릭하면 나오는 블록에서 찾을 수 있어요. 「만약 이라면」 블록은 톱니바퀴를 눌러 「아니고 만약」 옵션을 왼쪽과 같이 메뉴의 개수만큼 추가해요. 노란색 부분에는 알맞은 명령어 블록을 직접 결합해 보고, 메뉴 2, 메뉴 3의 값을 가져와 더하면 돼요.

▶ 해 보기 · 총 금액 계산을 파이썬으로 흉내 내기 (빈칸 채우기)

블록의 흐름을 파이썬으로 옮겼어요. 메뉴1 단가 5000은 교과서 192쪽의 값이고, 메뉴2·3 단가는 연습용으로 정한 값이에요. 총 금액을 구하는 줄의 ___는 메뉴2·메뉴3 값을 더하는 부분이에요. 빈칸을 채우기 전에는 NameError가 나는 게 정상이에요. 채워서 실행해 보고, 말한 문장을 바꿔 숫자가 없을 때도 확인해 봐요.

앱 제작은 화면 개발 → 기능 개발 → 테스트 → 패키징 및 배포 4단계로 한다. 화면은 배치 안에 레이블·버튼을 넣고 속성(높이·너비·글꼴 크기)을 정해 만든다.
기능은 블록으로 만든다. 앱이 켜지면 환영 인사를 말하고, 메뉴 버튼을 누르면 수량을 묻고 음성 인식을 시작하며 선택한 메뉴를 변수(종류)에 저장한다.
말한 문장에서 숫자를 골라내 숫자가 있으면 총 금액을 계산해 음성으로 안내하고, 없으면 다시 말해 달라고 한다. 종료 버튼은 한 번 더 물어본 뒤 앱을 끝낸다.
