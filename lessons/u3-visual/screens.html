⌨️ 그래프를 그리는 코드 · 읽는 코드 (96~97쪽)

구글 코랩에서 matplotlib으로 그리는 코드예요. 그래프 이름만 다르고 모양은 같아요.

① 선그래프를 그려 보자. 
import matplotlib.pyplot as plt   # 그래프를 그리기 위한 라이브러리
# x축(연도), y축(최고 기온) 값으로 선그래프 그리기
plt.plot(data['연도'],data['최고 기온'])
plt.xlabel('year')               # x축 레이블 설정

plt.show()                       # 그래프 보여 주기
② 막대 그래프를 그려 보자. 
# x축(연도), y축(최고 기온) 값으로 막대 그래프 그리기

plt.xlabel('year')               # x축 레이블 설정
plt.ylabel('temp')               # y축 레이블 설정
plt.show()                       # 그래프 보여 주기
③ 산점도를 그려 보자. 
# x축(연도), y축(최고 기온) 값으로 산점도 그리기
plt.scatter(data['연도'],data['최고 기온'])
plt.xlabel('year')               # x축 레이블 설정
plt.ylabel('temp')               # y축 레이블 설정
plt.show()                       # 그래프 보여 주기
④ 히스토그램을 그려 보자. 
plt.hist(data['최고 기온'], color = 'r')   # 빨간색으로 최고 기온 히스토그램 그리기
plt.hist(data['평균 기온'], color = 'g')   # 초록색으로 평균 기온 히스토그램 그리기

plt.xlabel('temp')               # x축 레이블 설정
plt.ylabel('count')              # y축 레이블 설정
plt.show()                       # 그래프 보여 주기

코드는 교과서에 인쇄된 대로 옮겼어요. 칼럼 이름('최고 기온' 등)은 앞 시간에 정한 칼럼 이름과 똑같이 써야 해요.

서울의 평균 최저 기온 그래프

쉽게 말하면선그래프로 서울의 평균 최저 기온을 그리면 오르락내리락하면서도 전체적으로 꾸준히 올라가는 모습이 보여요. 또 연도 구간을 골라 1980~1990년대만 따로 떼어 그릴 수도 있어요.

5️⃣ 서울 지역의 평균 최저 기온 그래프 · 읽는 코드 (98쪽)

plt.rc('font', family = 'NanumGothic')       # 글꼴 설정, 그래프에 한글 적용 가능

💡 교과서 말풍선 · 굵게 표시한 axes.unicode_minus 줄은 맷플롯립으로 그래프를 그릴 때 마이너스(-) 값을 x축이나 y축에 표시하려면 꼭 필요한 코드예요.

결과 해설 · 연도와 평균 최저 기온의 좌푯값을 선으로 연결한 그래프가 그려져요. 서울 지역의 연도(x축) 동안 평균 최저 기온(y축)이 꾸준히 상승하는 추세인 것을 확인할 수 있어요.

6️⃣ 1980~1990년대만 골라 그리기 · 읽는 코드 (98쪽)

# 연도가 1980 이상 2000 미만인 행들만 data1에 저장
data1 = data.loc[(data['연도'] >= 1980)&(data['연도'] < 2000)]
plt.title('서울의 1980~1990년대 평균 최저 기온')            # 그래프 제목 표시
# x축(연도), y축(평균 최저 기온)으로 초록색 선그래프 그리기
plt.plot(data1['연도'], data1['평균 최저 기온'], color = 'g')
plt.xlabel('연도')                                       # x축 레이블 설정
plt.ylabel('온도')                                       # y축 레이블 설정
plt.show()                                               # 그래프 보여 주기

결과 해설 · 1980년 이후부터 2000년 이전의 행들만 골라내서 연도와 평균 최저 기온의 좌푯값을 선으로 연결한 그래프가 그려져요. 1980~1990년대의 평균 최저 기온이 꾸준히 상승 중인 것을 확인할 수 있어요.

💡 교과서 말풍선 · 맷플롯립으로 그래프를 그릴 때 x축, y축 값은 자동으로 알아서 표현돼요. x축에 표시된 연도를 1980.0은 1980년, 1982.5는 1982년으로 보면 돼요.

03

분석 결과 해석과 그래프의 착시

교과서 99쪽 · 해석, 해 보기, 더 알아보기(그래프 해석의 주의점)

쉽게 말하면그래프는 한눈에 이해하기 쉽지만, 세로축 눈금 범위를 어떻게 잡느냐에 따라 같은 데이터가 완전히 다르게 보일 수도 있어요. 그래서 그래프를 볼 때는 축의 숫자와 원래 데이터를 꼭 함께 확인해야 해요.

4️⃣ 분석 결과 해석 (99쪽)

기온 데이터의 추이를 분석해 기후 변화의 심각성을 알리기 위해, 정형 데이터로 다양한 시각화 그래프를 그려 보았어요. 그리고 과거부터 현재까지 기온이 꾸준히 상승하고 있다는 사실을 서울 지역의 평균 최저 기온 시각화 작업으로 알아낼 수 있었어요. 다른 지역의 기온 데이터까지 분석한 결과를 해석하여 기후 변화 상황을 파악하고, 시각화한 자료와 함께 제시한다면 사람들에게 기후 변화의 심각성을 쉽게 알릴 수 있을 거예요.

👍 시각화 자료의 장점직관적으로 이해하기 쉬워요.
⚠️ 조심할 점그래프의 형태나 이미지의 표현 방식에 따라 착시 현상이 일어나거나 왜곡된 정보를 전달하기도 해요.

📝 해 보기 · 데이터를 분석하여 의미 파악하기 (99쪽 분석·토의)

① 기온 데이터 시각화 분석 결과를 해석해 보자. 서울 이외 다른 지역의 기온도 상승하고 있는가? 기간별, 기온별로 분석했을 때의 기온은 어떻게 변화하고 있는가?

② 친구들과 서로 분석 결과를 공유해 보고, 기후 변화의 심각성에 대해서 토의해 보자.

🔍 더 알아보기 · 그래프 해석의 주의점 (99쪽)

한 학생의 수학 성적 향상 추이를 보여 주는 그래프 두 개예요. 언뜻 보았을 때 (나)의 기울기가 (가)보다 더 가파르게 보여 성적이 획기적으로 향상된 것처럼 착각할 수 있어요. 그러나 세로축의 성적 표시 구간이 (가)는 10점 단위, (나)는 2점 단위로 설정되어 있어요. 같은 통계지만 성적 표시 구간을 다르게 했더니 (나)의 성적이 (가)보다 더 급격히 향상한 것처럼 보여요.

(가) 세로축 10점 단위
(나) 세로축 2점 단위

교과서 그림은 글로 다시 그렸어요. 점수(83·85·88·89점)는 두 그래프가 같은 값이라는 것을 보이려고 연습용으로 만든 값이에요.

선그래프(plot)·막대 그래프(bar)·산점도(scatter)·히스토그램(hist)은 같은 데이터를 다른 모습으로 보여 주고, 시간에 따른 변화를 볼 때는 두 변수의 관계를 선으로 이은 선그래프가 가장 알맞다.
서울의 평균 최저 기온 선그래프는 오르내리면서도 전체적으로 꾸준히 상승하는 추세를 보여 주고, 조건으로 연도 구간(1980 이상 2000 미만)을 골라 같은 방법으로 그릴 수 있다.
시각화 자료는 이해하기 쉽지만 세로축 눈금 범위나 축의 생략에 따라 착시·왜곡이 생길 수 있어서, 의심될 때는 원래의 통계 데이터와 비교해 해석해야 한다.
