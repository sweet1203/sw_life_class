01

스포츠 기록 분석 연구원

교과서 109쪽 · 데이터 분석으로 스포츠 팀의 성적이 향상될 수 있을까?

쉽게 말하면경기에서 나오는 기록을 숫자로 모아 분석해서, 팀이 이기는 데 도움이 되는 근거를 찾는 사람이 스포츠 기록 분석 연구원이에요.

📜 스포츠 기록 분석은 어떻게 발전했을까? (109쪽)

1990년대 초반영국 카디프 웨일스대학교(UWIC)의 연구팀들이 스포츠 경기를 객관적으로 분석하는 방법을 체계화하면서 본격적으로 발전했어요.
2002년 한일 월드컵과학적인 데이터 분석으로 월드컵 4강의 신화를 이루었고, 이를 계기로 국내에서도 데이터 분석의 중요성이 부각되기 시작했어요.
지금선수들의 기록 분석은 승패를 예측하거나 선수들의 기량을 파악하여 전략을 세우는 데 사용돼요.

수많은 데이터의 내용 중 어떤 항목을 분석에 사용하느냐에 따라 정확도와 신뢰도가 달라져요. 이렇게 스포츠 선수와 팀의 성과를 과학적으로 분석하는 사람이 바로 스포츠 기록 분석 연구원이에요.

🧑‍🔬 스포츠 기록 분석 연구원이 하는 일 (109쪽)

기록하고 분석하기각종 스포츠 경기의 모든 요소를 수치화된 데이터로 기록하고 이를 분석해요. 육상, 수영 등의 개인 종목과 축구, 야구 등의 단체 종목에서 나오는 기록을 체계적으로 정리해요.
객관적인 근거 찾기경기의 특성과 내용에 맞게 분석하고, 수치로 나타나는 객관적인 근거로 상대 팀이나 선수의 기록과 전략을 파악해요.
시스템과 기법 연구하기경기를 객관적으로 분석하기 위한 기록 시스템과 분석 기법을 개발하고, 다양한 분석 기법과 통계를 활용한 학문적인 연구를 해요.

교과서의 [자료 6]은 경기장에서 노트북 등으로 경기를 지켜보며 기록·분석하는 모습, [자료 7]은 경기 화면 위에 선수의 움직임을 점과 선으로 겹쳐 분석하는 화면의 예예요. 사진은 이곳에 싣지 않고 글로 옮겼어요.

🗣️ 해 보기 · 목적에 맞는 데이터 유형 탐색하기 (109쪽 · 분석·토의)

해 보기스포츠 팀을 구성할 때 중요한 요소가 무엇인지 생각해 보고, 팀 구성을 위해 어떤 데이터를 수집하여 분석할지 친구와 토의해 보자.

실습 · 선수 데이터를 분석해 선발팀 구성하기 — 데이터 수집

교과서 110쪽 · 1단계 데이터 수집

쉽게 말하면먼저 어떤 자료로 무엇을 할지 정하고, 세계 축구 선수들의 기록이 담긴 players_21.csv 파일을 내려받아 열어 봐요. 한 줄이 선수 한 명, 한 칸이 속성 하나예요.

📋 실습 개요 (110쪽)

지난 시즌 5연패로 리그를 마감한 축구팀이 있어요. 올해는 기필코 승리를 쟁취하고자 선수 데이터를 철저히 분석해 팀을 꾸리기로 했어요. 개념 학습에서 배운 데이터 분석 단계에 따라 선수 데이터를 분석하고, 이를 활용해 새로운 선발팀을 구성해 봐요.

문제 상황5연패의 늪에 빠진 축구팀의 첫 승리를 위해 선수들의 데이터를 분석해 선발팀을 구성해야 한다.

📥 1 데이터 수집 (110쪽)

기록 분석을 위해 세계 축구 선수들의 데이터를 수집해 봐요. 데이터는 캐글(Kaggle)에서 내려받을 수 있어요.

  1. 캐글 사이트에서 「FIFA 22」 선수 정보가 취합된 데이터를 검색해요. 캐글은 로그인(구글 계정과 연동)을 해야 데이터를 내려받을 수 있어요.
  2. 다운로드 버튼을 눌러 파일을 내려받고, 분석에 사용할 players_21.csv 파일을 찾아요. 해당 파일만 받고 싶으면 스크롤을 내려 Data Explorer에서 파일 이름을 찾아 클릭한 뒤 내려받기 버튼을 눌러요.
  3. 받은 파일을 열어 데이터를 확인해요. 선수별로 110개의 칼럼(이름, 포지션 등의 속성)이 있어요.

데이터를 확인해 보면 선수별 결측값이 있어요. 이는 선수별 포지션에 따른 차이이거나 분석에 크게 영향을 주지 않는 것이라서, 그대로 두고 사용해요.

주의관련 데이터를 수집할 때 선수들의 사생활을 침해하거나 민감한 내용이 들어 있지 않은지 살펴보고, 개인 정보 등 불필요한 정보까지 수집하지 않도록 해야 해요.

🧹 2 데이터 처리 (111쪽)

수집한 players_21.csv 파일을 열어 FIFA에서 제공하는 선수들의 데이터를 확인해 보아요. csv 파일의 인코딩 방식 때문에 한글이 깨져 보이는 현상은 데이터를 불러오는 방법을 바꿔 해결할 수 있어요.

① 스프레드시트로 열기엑셀에서는 [데이터] 메뉴의 [데이터 가져오기] → [텍스트/CSV]를 눌러 파일을 열고, 파일 원본을 [65001: 유니코드(UTF-8)]로 선택하면 모든 글자가 제대로 나타나요.
② 오렌지에서 File 위젯으로 열기오렌지를 열고 [Data] 카테고리의 File 위젯을 작업창으로 끌어 와요. 더블 클릭한 뒤 폴더 모양 버튼으로 players_21.csv가 있는 위치를 지정해요.
③ Info에서 정보 확인하기File 위젯 창의 [Info]에서 데이터의 정보를 확인해요. 아래에서 줄을 눌러 뜻을 살펴봐요.
스프레드시트표에 숫자나 문자 데이터를 입력하고 이를 조작하여 데이터를 처리하는 소프트웨어예요. 단순한 계산뿐 아니라 데이터를 도표로 나타내는 그래픽 기능과 데이터베이스 기능, 문서 작성 기능도 있어요.
오렌지데이터를 분석하기 위한 오픈 소스 소프트웨어로, 설치해서 사용해요. 위젯을 끌어다 놓는 간단한 과정으로 데이터를 분석하고 직관적으로 시각화할 수 있어요.

스포츠 기록 분석 연구원은 경기의 모든 요소를 수치화된 데이터로 기록하고 분석해, 팀과 선수의 성과를 과학적으로 분석해요. 어떤 항목을 쓰느냐에 따라 정확도와 신뢰도가 달라져요.
선수 데이터는 수집 → 처리 → 시각화 → 분석 결과 해석의 4단계로 분석해요. 오렌지에서는 Select Rows로 조건에 맞는 선수를 뽑고 Bar Plot으로 그려요. 기본 파이썬으로는 리스트에서 조건으로 골라 정렬할 수 있어요.
분석 결과는 선발과 팀 구성의 유일한 기준은 아니지만 도움이 돼요. 개인 정보는 필요한 내용만 안전하게 다루고, 올바른 절차로 얻은 데이터인지, 조작·편향은 없는지 검증해야 해요.
