## pyrun 목록
- **bdRun** (03): `number=10` 회색 사람 → `random.randrange`로 한 명 노랑(즐거움 버튼) → 「나」 추가·빨강(고마움) → `colors.count('yellow'/'red')`를 모니터처럼 출력. 로컬 `python3`로 확인(`number`는 1 이상).

## 커스텀 체험
- 02 작동 순서 따라가기: 9×9 칸, 회색 8명 무작위 배치. 버튼 ①처음 / 감정 하나 주기(한 명 노랑) / ②한 번 움직이기(각자 위·아래·왼·오 중 무작위 한 칸, 벽이면 제자리) / ③만나면 색 전달 / ④ ②·③ 5번 반복. ② 합계 최대 30번에서 버튼 비활성, 다시 = ①. 모니터: ② 횟수·노란 사람 수. 자동 재생 없음.
- 03 인터페이스 모형: 147쪽 화면 구성 예시 배치(왼쪽 setup·go·즐거움·슬라이더·플롯·모니터, 오른쪽 나·고마움·방향 4). 부품을 누르면 Commands·Display name·Action key / Global variable·Minimum·Maximum·Value / Pen update commands / Reporter를 카드로 표시(146~149쪽·nlogo 값). 좁은 화면(560px 미만)에서는 가운데 검은 월드를 숨기고 2열.

## 선생님 확인할 점
- **「만남」 정의**: 교과서 ③은 「두 사람이 만나면」이고 넷로고 코드(다음 차시)는 같은 패치에 있을 때 전달됨. 작동 순서 체험은 9×9 작은 마당에서 잘 보이도록 **같은 칸 또는 바로 옆 칸**을 만난 것으로 쳤음(화면에 밝힘). 마당 크기·사람 8명·한 번에 한 칸·최대 30번은 연습용 값.
- **대면·비대면 풀이**: 교과서에는 관찰 내용에만 있고 핵심 요소에서 빠진 이유가 인쇄돼 있지 않음. 옆 설명(직접 만났을 때의 감정 전이를 목적으로 함)을 근거로 `sorter` 해설에 「목적이 직접 만났을 때의 감정 전이라서 따로 두지 않았다고 볼 수 있어요」라고 쓴 것은 제작자의 풀이.
- **슬라이더 기본값**: 교과서 본문은 Value 10(149쪽), 소스 파일 `147쪽_화면구성.nlogo`는 40. 교과서 본문대로 10으로 씀.
- **색 칩**: 교과서 해 보기는 자유 기술(예 고마움(빨간색)·즐거움(노란색)). 색 칩 6가지(노랑·빨강·초록·파랑·주황·분홍)는 고르기 편하라고 제작자가 정함. 교과서 TIP의 이모티콘은 넣지 않음.
- **그림을 글·도형으로 옮긴 곳**: 144쪽 야구장 사진·말풍선 그림, 145쪽 사람 그림, 146~149쪽 넷로고 캡처(→ 설정 표·인터페이스 모형). 화면 구성 코드(`plot count turtles with [color = yellow]` 등)는 인쇄본 그대로.
- 입력/출력 `sorter`의 감정 버튼·방향 버튼 분류는 143쪽 「입력(버튼, 슬라이더 등)」 문장과 149쪽 해 보기 문장을 근거로 한 판단.
