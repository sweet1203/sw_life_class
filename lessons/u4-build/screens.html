실습 · 시뮬레이션 모델로 감정 전염 현상 분석하기 (144쪽)

감정 전염은 상대방의 얼굴, 표정, 자세 등을 무의식적으로 모방하고 상대방에게 감정적으로 동화되는 경향을 의미해요. 사람들은 어떻게 서로의 감정에 영향을 받으며 물들어 갈까요? 사회 현상 분석가가 되어 다른 사람과 감정을 주고받는 사람들의 모습을 시뮬레이션해 봐요.

2 개념적 모델링

교과서 145쪽 · 핵심 요소 추출과 작동 순서

쉽게 말하면현실의 모습에서 꼭 필요한 것만 골라 단순하게 나타내는 것이 추상화예요. 그다음 누가 어떤 규칙으로 움직이는지(작동 순서)를 정해요.

🧮 현실 세계 추상화 (145쪽)

다른 사람과 감정을 주고받는 모습을 시뮬레이션하기 위해 고려해야 할 중요한 요인은 무엇일까? 시뮬레이션의 목적과 관찰 내용을 살펴본 후, 핵심 요소를 추출하여 현실 세계를 추상화해 보자.

시뮬레이션 목적다른 사람과 감정을 주고받는 사람들의 모습을 표현
관찰 내용감정을 주고받는 사람 수, 나, 다른 사람, 감정, 대면, 비대면
핵심 요소감정을 주고받는 사람 수, 나, 다른 사람, 주는 감정, 받는 감정
교과서 옆 설명사람들이 직접 만났을 때 주고받는 감정의 전이를 시뮬레이션의 목적으로 하여 감정을 주고받는 사람 수, 나, 다른 사람, 주는 감정, 받는 감정을 중요한 요인으로 둡니다.

관찰 내용 가운데 핵심 요소로 남기는 것은? 하나씩 골라 보세요.

🎞️ 시뮬레이션 작동 순서(행동 규칙) (145쪽)

추상화한 내용을 바탕으로 상호 작용하는 사람들 사이에 감정이 전달되는 기능을 계획해 보자. 다음과 같이 시뮬레이션 작동 순서(행동 규칙)를 설계할 수 있다.

  1. ① 감정을 주고받기 전, 사람들은 회색이다(가정: 기본 감정은 없다).
  2. ② 감정을 주고받는 사람들은 랜덤으로 움직인다.
  3. ③ 만약 두 사람이 만나면 감정이 전달되어 사람의 색이 바뀐다.
  4. ④ 위 ②, ③번의 과정을 반복한다.

▶ 작동 순서 따라가기 (체험)

작은 마당(9×9칸)에 회색 사람 8명이 있어요. 버튼을 차례로 눌러 ①~④를 따라가 보세요. 여기서는 잘 보이도록 같은 칸이거나 바로 옆 칸에 있으면 만난 것으로 쳐요.

회색(감정 없음)노란색(감정을 받은 사람)
②를 한 횟수0 / 30
노란 사람 수0

마당 크기, 사람 수(8명), 한 번에 한 칸씩 움직이는 것, 옆 칸까지 만난 것으로 치는 것, 최대 30번은 체험하기 좋게 정한 값이에요. 난수라 「①」을 누를 때마다 처음 위치가 달라져요. 교과서의 넷로고 모델은 다음 시간에 코드로 살펴봐요.

3 화면 구성

교과서 146~149쪽 · 버튼 · 슬라이더 · 플롯 · 모니터

쉽게 말하면사용자가 조건을 넣는 부품(버튼·슬라이더)과 결과를 보는 부품(플롯·모니터)으로 시뮬레이션 화면을 꾸며요. 넷로고의 Interface 창에서 해요.

🪜 화면 구성 순서 (146쪽)

넷로고의 인터페이스 창을 클릭하면 시뮬레이션 모델 화면을 구성할 수 있어요. 사용자가 조건을 입력할 수 있는 버튼과 슬라이더, 결과를 출력하는 플롯과 모니터를 만들어 화면을 구성해요. 2·3·4단계 설명은 148~149쪽에 있어요.

1단계 · 버튼 만들기조건 설정 버튼, 실행 버튼, 감정 버튼, 나 버튼, 방향 버튼
2단계 · 슬라이더 만들기number(사람 수)
3단계 · 플롯 만들기감정 전달된 사람 수(그래프)
4단계 · 모니터 만들기내가 받고 싶은 감정 모니터, 내가 주고 싶은 감정 모니터

🖥️ 넷로고 인터페이스 모형 (147쪽 화면 구성 예시를 다시 그림)

부품을 눌러 보세요. 어떻게 설정하는지 아래에 나와요.

교과서에서는 명령어 코드를 넣기 전이라 모든 버튼 이름이 빨간색으로 나타나요. 여기서는 부품의 배치와 설정 내용을 글과 도형으로 옮겼어요.

🔘 방향 버튼 설정 · 1단계 요약 (147쪽)

방향값을 설정하기 위해 move 뒤에 방향의 각도를 입력해요. Action key 값을 입력하면 키보드로도 방향을 조작할 수 있어요. 아래 표대로 채우면 방향 버튼을 쉽게 만들 수 있어요.

TIP · 1단계 버튼 만들기 요약
  1. 조건 설정 버튼 · [setup] 버튼을 누르면 테스트하고자 하는 조건으로 설정돼요. Commands에 setup을 입력해요.
  2. 실행 버튼 · [setup] 버튼을 누른 후 [go] 버튼을 누르면 모델이 실행돼요. Commands에 go를 입력하고, go에 해당하는 코드를 무한 반복하기 위해 go 버튼의 forever 체크 박스를 클릭해요.
  3. [나] 버튼 · 이 버튼을 누르면 크기가 큰 사람인 「나」가 나타나요. Commands에 me(나)를 입력해요.
  4. 감정 버튼 · 이 버튼을 누르면 감정을 가진 사람이 생겨요. Commands에 joy(즐거움), thanks(고마움)를 입력해요.
  5. 방향 버튼[위, 오른쪽, 아래, 왼쪽] · 각 버튼을 누르면 「나」가 해당 방향으로 움직여요(방향 버튼 설정하기 표 참고).

📈 플롯과 모니터에 넣는 코드 (148~149쪽)

플롯(Plot)은 시뮬레이션 모델에서 계산한 값을 그래프로 출력하고, 모니터(Monitor)는 실행하는 도중 즐거움과 고마움에 해당하는 수를 실시간으로 보여 줘요. 선 색은 내가 정한 감정의 색으로 골라요.

플롯 · Pen update commands 
plot count turtles with [color = yellow]
plot count turtles with [color = red]

노란색 선은 즐거운 감정을 전달받은 사람의 수(y축), 빨간색 선은 고마운 감정을 전달받은 사람의 수예요.

모니터 · Reporter 
count turtles with [color = yellow]
count turtles with [color = red]

첫 줄은 즐거움 모니터, 둘째 줄은 고마움 모니터에 넣어요.

슬라이더는 Minimum에 0, Maximum에 100, Value에 사람 수의 기본값으로 10을 입력해요(149쪽).
