쉽게 말하면빈 값이 있으면 그래프가 끊겨 보여요. 그래서 빈 값을 지우거나, 다른 값으로 채워 정리해요. 또 칼럼 이름에 특수 기호가 있으면 쓰기 불편하니 이름도 깔끔하게 바꿔요.

🧹 결측치를 처리하는 방법 (95쪽 ❻)

⑤에서 나타난 결측치를 처리해요. 결측치를 처리하는 방법에는 삭제하기, 주변 값으로 채우기, 0으로 채우기 등 다양한 방법이 있어요. 기온 데이터는 결측치 개수가 적으니 해당 행을 삭제하는 방법을 써요.

삭제하기빈 값이 있는 행을 지워요. 이 실습에서 쓰는 방법이에요.
주변 값으로 채우기변수별 평균 같은 값으로 빈 칸을 메워요.
0으로 채우기빈 칸에 0을 넣어요.
data = data.dropna(axis = 0)  # data의 빈값이 있는 행을 삭제해서 data에 저장
data                          # data의 내용 출력

코드 가이드

결과는 111 rows × 8 columns로, 1907년을 포함한 결측치 줄 3개가 사라져요.

✏️ 칼럼명 바꾸기 (95쪽 ❼)

데이터 칼럼명을 사용하기 쉽게 변경해요. 특수 기호를 빼고 칼럼명을 정리해 봐요.

# data의 컬럼명 변경
data.columns = ['지점', '지점명', '연도', '평균 기온', '최저 기온', '최고 기온', '평균 최저 기온', '평균 최고 기온']
data    # data의 내용 출력
🔬 박사님 말풍선 칼럼명을 변경하지 않으면 그래프를 그리는 단계에서 특수 기호 등의 입력이 번거롭게 돼요.
