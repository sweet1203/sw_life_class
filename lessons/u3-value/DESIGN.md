**데이터·코드 규칙**
- 교과서 코드(`pip`·`konlpy`·`pandas`·`wordcloud`·코랩)는 인쇄본 그대로 읽기용 카드. pyrun은 순수 파이썬(`re`·리스트·딕셔너리).
- pyrun ①의 글은 100쪽 노트북(`100쪽_…ipynb`) data 출력, 곧 교과서 101쪽 화면에 나온 글의 앞 세 줄. pyrun ②의 명사 131개는 같은 노트북의 `hannanum.nouns` 출력 전체라서 결과(두 글자 이상 107개, 기후위 7·에너지 6·대응 5·배출량 4)가 교과서와 같음(검증함).
- 워드 클라우드 체험의 앞 네 줄(7·6·5·4)은 교과서 103쪽 인쇄값, 나머지(오늘 3·탄소중립 3 이하)는 같은 노트북 `dic_word` 출력에서 옮김.
- 개념학습_실습코드(전체).txt·지도서·hwp·QR 105쪽 시각화 정답은 읽거나 쓰지 않음. 106쪽 활동 정리 예시(PPT에 있음)·104쪽 활동 칸 빈 곳은 넣지 않음. 104쪽 「예시」 칸의 사이트 이름·작업 경로·파일명·중요 단어는 교과서 인쇄 내용이라 그대로 둠(사이트 주소는 뺌).

**확인할 점**
- 폴더의 `temp_text.txt`는 「기후 위기」처럼 띄어쓰기가 있는데, 교과서 101쪽 화면과 노트북은 「기후위기」(붙여 씀)이고 그래서 Hannanum 결과가 「기후위」다. pyrun ①은 교과서 인쇄본(붙여 쓴 쪽)을 따름.
- 103쪽 코드 ②의 주석이 인쇄본에서 `from collections import Counter  # 수치 연산 패키지`처럼 어색함(Counter·numpy 설명이 서로 바뀐 듯). 인쇄된 그대로 옮김.
- Hannanum이 「기후위기」를 「기후위」로 자르는 까닭은 교과서가 따로 설명하지 않아서 화면에서도 설명하지 않고 해 보기 ②(Okt) 메모로 둠. Okt 결과는 105쪽 화면 앞부분('먼저','기후','위기','대응','위','에너지')만 옮김.
- 날씨마루 사이트 주소는 교과서에 QR만 있어 이름만 적음. 환경부 열린장관실·김해시 누리집 주소는 학생 화면에 넣지 않고 기관·메뉴 이름만 적음.
- 이미지에서 글로 옮긴 곳: 100~101쪽 화면 캡처(메모장·코랩 출력) → 글, 104쪽 워드 클라우드 그림 → 체험으로 대체, 105쪽 Okt 워드 클라우드 그림 → 생략, 107쪽 사진 생략.
- 제작자가 만든 것: 01 「내용 살펴보기」 카드의 제목(내용은 교과서 문장), 사회적 가치 분류 게임의 해설, 인터뷰 질문 카드의 요약 문장(원문을 줄임), 인터뷰 메모 질문(intThink), 해 보기 메모 질문 일부(josaFind·freqNote·weatherTry), 퀴즈 오답 보기와 해설.
- 106쪽 성취도 점검 5항목은 교과서 문장 그대로(보충하기 쪽 포함).
