① 통계 데이터 수집 (117쪽)

국가통계포털(KOSIS)에 접속한 뒤, 검색창에 「주민등록인구」를 입력해요. 검색 결과 중 통계청의 「주민등록인구」를 선택해요. 통계 목록 창이 뜨면 [인구] 폴더에서 「주민등록인구」와 「출생아수」를, [가족] 폴더에서 「1인가구비율」 데이터를 내려받아요. 화면의 순서와 수치는 접속 시기에 따라 달라질 수 있어요.

참고 · 데이터 저장 시 설정 안내
행렬전환표측은 「시점」, 표두는 「행정구역별」로 위치를 바꿔요.
조회설정항목은 「계」를 고르고, 행정구역별은 「전체해제」를 누른 뒤 「전국」을 골라요. 시점은 전체선택을 해제하고 「년」을 고른 뒤 시작 연도를 「1997년」으로 정해요. (1인가구비율은 「전체년도」를 골라요.)
다운로드파일 형태는 CSV를 골라요.

📈 선그래프 · 주민 등록 인구수 변화 (119쪽)

교과서 표의 그래프 코드는 plt.plot(선그래프), 데이터 코드는 data['연도'], data['주민 등록 인구수']예요. 코드는 읽기만 해요. 아래에서 값을 읽어 볼 수 있는 그래프로 대신 보여 줄게요.

import pandas as pd # pandas 라이브러리 추가
data = pd.read_csv('주민 등록 인구수.csv', encoding='cp949')

import matplotlib.pyplot as plt #그래프를 그리기 위한 라이브러리
plt.rc('font', family = 'NanumGothic') # 글꼴 설정, 그래프에 한글 사용

plt.title('주민 등록 인구수 변화') # 그래프 제목

# x축(연도), y축(주민 등록 인구수)값으로 선 그래프 그리기
plt.plot(data['연도'], data['주민 등록 인구수'])
plt.xlabel('연도') # x축 레이블 설정
plt.ylabel('인구수') # y축 레이블 설정

# y축에 표현되는 값 읽어들이기
current_values = plt.gca().get_yticks()
# y축 숫자에 천 단위 기호(,) 적용
plt.gca().set_yticklabels(['{:,.0f}'.format(x) for x in current_values])

plt.show() # 그래프 보여주기
코드 가이드 (파란 부분)
plt.plot(x, y)x축 값(연도)과 y축 값(주민 등록 인구수)으로 선그래프를 그려요.
get_yticks() 와 set_yticklabels()y축에 표시되는 값을 읽어 와서, 아주 큰 숫자를 한번에 읽기 쉽도록 천 단위 기호(,)를 붙여 다시 적어요.
그래프로 살펴보기 · 주민 등록 인구수 (1997~2022)

📊 막대그래프 · 인구 변화 (119쪽)

두 데이터를 합친 뒤 plt.bar(막대그래프)를 두 번 써서 「주민 등록 인구수」와 「출생아 수」를 같은 그래프에 겹쳐 그려요. label은 범례에 나올 이름이에요.

import pandas as pd # pandas 라이브러리 추가
data1 = pd.read_csv('주민 등록 인구수.csv', encoding='cp949')
data2 = pd.read_csv('출생아 수.csv', encoding='cp949')

plt.title('인구 변화') # 그래프 제목

data = pd.merge(data1, data2, on='연도')

# x축(연도), y축(주민 등록 인구수) 값으로 막대그래프 그리기
plt.bar(data['연도'], data['주민 등록 인구수'], label='주민 등록 인구수')

# x축(연도), y축(출생아 수) 값으로 막대그래프 그리기
plt.bar(data['연도'], data['출생아 수'],label='출생아 수')

plt.xlabel('연도') # x축 레이블 설정
plt.ylabel('인구수') # y축 레이블 설정

# y축에 표현되는 값 읽어들이기
current_values = plt.gca().get_yticks()
# y축 숫자에 천 단위 기호(,) 적용
plt.gca().set_yticklabels(['{:,.0f}'.format(x) for x in current_values])

plt.legend() # 범례 표시
plt.show() # 그래프 보여주기

앞 단계에서 만든 data1(주민 등록 인구수)과 data2(출생아 수)를 on='연도'로 합친 것이 pd.merge(data1, data2, on='연도')예요. 코드는 교과서의 119쪽 소스 코드를 옮긴 것이에요.
