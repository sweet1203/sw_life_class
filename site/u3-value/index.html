01

데이터 수집 · 텍스트 글 모으기

교과서 100쪽 · 연설문 복사하기, 메모장에 저장하기, 내용 살펴보기

쉽게 말하면분석할 글을 찾아서 복사해 메모장에 저장하면 텍스트 데이터가 준비돼요. 그다음 내용이 알맞은지, 줄바꿈이 고른지, 이름 같은 개인 정보가 없는지 살펴보고 정리해요.

1️⃣ 데이터 수집 (100쪽)

기후 변화와 관련된 내용을 분석하기 위해 연관성 있는 텍스트를 수집해 보아요.

① 글 고르기

환경부 열린장관실의 말과글 → 연설문/축사에서 원하는 내용을 선택해요. 교과서 예시에서는 「2022 에너지대전환포럼」 연설문을 사용했어요.

② 복사해서 저장하기

선택한 내용을 복사해서 메모장에 붙여 넣고 텍스트 파일로 저장해요. 텍스트 파일의 줄바꿈 상태가 고르지 않을 수 있어요. 실습 파일 이름은 temp_text.txt예요.

💡 TIP · 텍스트 데이터 수집 방법 내가 원하는 텍스트 데이터를 검색해서 내용을 복사해 메모장에 붙여 넣고 저장해요. 메모장에 원하는 내용을 직접 입력해도 돼요.

2️⃣ 데이터 처리의 첫걸음 · 글 살펴보기 (100쪽)

메모장에 붙여 넣은 텍스트 파일의 내용이 적절한지 파악해 보아요. 카드를 눌러 무엇을 살펴야 하는지 확인해요.

⚠️ 주의 인터넷에서 검색해서 내려받은 내용이나 내가 사용하고자 하는 글에 개인 정보와 같은 민감한 내용이나 허위 사실 등이 포함되어 있지 않은지 살펴봐야 해요.

📖 비정형 데이터란? (100쪽)

비정형 데이터는 구조화되지 않은 형태로 텍스트, 이미지, 동영상과 같은 데이터로 구성돼요. 표처럼 칸이 나뉜 정형 데이터(앞 시간의 기온 데이터)와 달리, 연설문 같은 글은 줄글 그대로라서 분석하기 전에 내용을 살펴 정리해야 해요.

02

데이터 불러오기와 전처리

교과서 101쪽 · 워드 클라우드 준비, 한글만 남기기, 단어로 나누기

쉽게 말하면글에는 숫자·기호·한자가 섞여 있어서, 먼저 한글만 남기고 나머지는 빈칸으로 바꿔요. 그다음 글을 단어별로 나누는데, 한국어는 「기후위기에」처럼 조사가 붙어 있어서 띄어쓰기만으로는 알맞게 나뉘지 않아요. 그래서 형태소 분석기가 명사만 뽑아 줘요.

☁️ 워드 클라우드란? (101쪽 주석 5)

텍스트 데이터를 시각화하기 위해 사용되는 기술로, 문서의 문구와 단어를 분석하여 중요도나 사용 빈도를 직관적으로 파악할 수 있도록 하는 표현 기법이에요.

1️⃣ 데이터 불러오기 · 읽는 코드 (101쪽)

① 워드 클라우드 관련 설치 파일 실행 
# 워드 클라우드 관련 설치 파일
!pip install nltk
!pip install konlpy
!apt-get update -qq
!apt-get install fonts-nanum* -qq
# 실행 후 [런타임] - [세션 다시 시작] 하면 워드 클라우드 작업을 위한 환경 준비

설치 파일을 실행하기 전, 코랩 환경에서 한글을 사용할 수 있도록 정형 데이터 실습과 같은 방법으로 글꼴을 먼저 설치해요.

② 데이터 업로드 
from google.colab import files        # 구글 코랩 환경에 파일 업로드를 위한 작업
uploaded = files.upload()             # 파일 업로드 작업 실행
③ 업로드한 데이터 확인 
data = open('temp_text.txt', encoding = 'UTF-8').read()   # 업로드한 파일을 열어서 data 변수에 저장
data                                                       # data 내용 출력

출력되는 글: 「먼저, 기후위기 대응을 위한 에너지 전환에 많은 관심을 가지고 …」 (줄바꿈은 \n으로 보여요.)

2️⃣ 데이터 전처리하기 · 읽는 코드 (101쪽)

① 불필요한 문자 제거하기 
# 불필요한 문자 제거하기
import re      # 정규 표현 처리를 위한 라이브러리
# 특수 문자, 한자, 공백 등을 제거하기 위한 정규 표현식-> [^가-힣]의 뜻: 한글이 아닌 모든 문자를 의미
data1 = re.sub('[^가-힣]', ' ', data)
data1      # data1 내용 출력

코드를 실행하여 원래 메모장 내용에서 숫자나 특수 기호 등이 제거되었는지 확인해요.

② 내용을 단어별로 구분하기 
import konlpy                       # 한국어 정보 처리를 위한 파이썬 패키지
from konlpy.tag import Hannanum     # 한글 형태소 분석기 중 Hannanum을 사용
hannanum = konlpy.tag.Hannanum()    # 형태소를 분석하여 hannanum에 저장
data2 = hannanum.nouns(data1)       # data1에서 명사(nouns)를 추출해서 data2에 저장
data2                               # data2 내용 출력

출력되는 글(교과서 화면의 끝부분): '축소', '병행', '재생에너지', '원전', '활용' … 명사만 뽑혀요.

💡 TIP · 형태소 분석이 필요한 이유 한글로 워드 클라우드 작업을 할 때, 영어와는 다르게 띄어쓰기를 기준으로 나누게 되면 그 의미를 제대로 파악하기가 힘들어요. 조사, 명사, 동사처럼 문장에 사용된 단어의 형태소를 분석해야 해요.

▶ 해 보기 · 한글만 남기고 띄어쓰기로 나눠 보기

교과서는 re.sub로 한글만 남기고, 형태소 분석기(konlpy)로 명사를 뽑았어요. 여기서는 같은 정규 표현식([^가-힣])으로 한글만 남긴 뒤, 띄어쓰기로만 나눠서 어떤 일이 생기는지 봐요. 연설문의 앞 세 줄이에요.

띄어쓰기로만 나누면 「기후위기」와 「기후위기에」가 서로 다른 낱말이 돼요. 교과서에서는 형태소 분석기가 조사를 떼어 내서 명사를 뽑았고, 이 낱말이 「기후위」로 나왔어요(105쪽에서 다시 만나요).

03

단어 정리와 빈도수 구하기

교과서 102~103쪽 · 데이터프레임, 글자 수, 정렬, 빈도수, 딕셔너리

쉽게 말하면뽑아 낸 명사에서 한 글자짜리를 빼고, 같은 단어가 몇 번 나왔는지 세어서 많이 나온 순으로 줄을 세워요. 마지막에는 「단어: 횟수」 짝(딕셔너리)으로 바꿔서 워드 클라우드에 넣을 준비를 해요.

단계별 읽는 코드 (102~103쪽 ③~⑧)

③ 단어별로 구분된 내용을 데이터프레임으로 
import pandas as pd                       # 데이터 핸들링을 위한 라이브러리
df_word = pd.DataFrame({'word' : data2})  # data2 내용을 데이터프레임으로 변환하여 df_word에 저장
df_word                                   # df_word 내용 출력
④ 단어들의 글자 수 추가 
df_word['count'] = df_word['word'].str.len()   # 단어(word)별 글자 수(count) 추가
df_word                                         # df_word 내용 출력

결과(앞부분): 기후위 3 · 대응 2 · 에너지 3 · 전환 2 · 관심 2

⑤ 글자 수 기준으로 오름차순 정렬 
df_word1 = df_word.sort_values('count')   # 글자 수 기준으로 정렬하여 df_word1에 저장
df_word1                                  # df_word1 내용 출력
⑥ 두 글자 이상의 단어만 남기기 
df_word2 = df_word1.query('count >= 2')   # 두 글자 이상 단어만 남겨 df_word2에 저장
df_word2                                  # df_word2 내용 출력
⑦ 단어별 빈도수 구하기 
df_word3 = df_word2.groupby('word', as_index = False).agg(n = ('word', 'count')).sort_values('n', ascending = False)
# 단어별로(word) 분리해서 구한 빈도수(n)를 내림차순으로 정렬하여 df_word3에 저장
df_word3                                  # df_word3 내용 출력

결과(앞부분): 기후위 7 · 에너지 6 · 대응 5 · 배출량 4

⑧ 데이터프레임을 딕셔너리로 
# 워드 클라우드는 단어는 키(key), 빈도수는 값(value)으로 구성된 딕셔너리 데이터 구조를 이용
dic_word = df_word3.set_index('word').to_dict()['n']   # df_word는 데이터프레임이므로 딕셔너리로 변환
dic_word

결과(앞부분): {'기후위': 7, '에너지': 6, '대응': 5, '배출량': 4, …} · 문서에서 자주 언급되는 단어가 빈도수 기준 내림차순으로 정렬되어 출력돼요.

💡 TIP · 딕셔너리 딕셔너리명 = {key1:value1, key2:value2, …}와 같이 콜론(:)으로 구분한 key(키)와 value(값)의 한 쌍으로 구성돼요. ⑧번 활동으로 워드 클라우드 작업을 위한 딕셔너리 형태인 dic_word = {'기후위' : 7, '에너지' : 6, '대응' : 5, …}가 준비된 상태예요.

워드 클라우드로 그리고 해석하기

교과서 103~105쪽 · 워드 클라우드 생성, 분석 결과 해석, 해 보기

쉽게 말하면「단어: 횟수」 딕셔너리를 워드 클라우드에 넣으면 많이 나온 단어일수록 큰 글씨로 그려져요. 큰 글씨의 단어가 이 글의 핵심 키워드이고, 이 단어들로 홍보 자료를 만들 수 있어요.

3️⃣ 데이터 시각화 · 읽는 코드 (103쪽)

구글 코랩에 준비한 데이터를 불러들여서 워드 클라우드로 시각화해요.

import matplotlib.pyplot as plt            # 생성한 워드 클라우드 데이터를 시각화하기 위해 사용
import matplotlib.font_manager as fm       # 폰트 확인
sys_font = fm.findSystemFonts()

# 마음에 드는 폰트 선택 (여기서는 나눔펜 글꼴 선택)
path = '/usr/share/fonts/truetype/nanum/NanumPen.ttf'

# 텍스트를 추출하고 빈도수를 추출하기 위해 사용
from collections import Counter       # 수치 연산 패키지

아래 「단어: 횟수」 목록이 딕셔너리라고 생각해요. 횟수가 클수록 글자가 커져요. 앞의 네 줄(기후위 7·에너지 6·대응 5·배출량 4)은 교과서 103쪽에 인쇄된 값이고, 나머지는 같은 실습 결과에서 옮긴 값이에요. 직접 고치거나 새 줄을 더해 「다시 그리기」를 눌러 봐요.

1회 이상

교과서의 워드 클라우드는 실행할 때마다 글자의 배열이나 크기, 색이 조금씩 달라지지만, 큰 글씨로 표현되는 단어들은 같아요. 여기서도 「섞어서 배치하기」를 눌러 보면 모양은 바뀌어도 큰 단어는 그대로예요.

4️⃣ 분석 결과 해석 (104쪽)

기후 변화와 관련된 비정형 데이터를 워드 클라우드로 시각화한 결과, 데이터 처리 단계에서 빈도수가 높았던 단어인 기후위, 에너지, 대응, 배출량 등이 큰 글씨로 표현된 것을 볼 수 있어요. 이 주요 단어(핵심 키워드)들을 활용해 홍보 자료를 구성한다면 더 많은 사람을 설득할 수 있어요.

비정형 데이터로 사회 현상을 분석할 때에는 데이터를 어디서, 얼마나 수집하느냐에 따라 분석 결과에 나타나는 핵심 키워드가 달라질 수 있어요. 그러므로 데이터 편향이 생기지 않도록 많은 양의 데이터를 다양한 곳에서 수집하는 것도 중요해요.

💡 TIP · x, y축 설정 방법x축과 y축의 숫자는 워드 클라우드를 만들 때 width와 height를 조절하면 돼요.
❓ 교과서의 물음「기후 위기」라는 단어가 「기후위」로 표현되었어요. 이를 제대로 표현하려면 필요한 작업은 무엇일까요? 105쪽 해 보기 ②에서 해결해 봐요.

📝 해 보기 ② · 형태소 분석기 바꿔 보기 (105쪽)

본문 101쪽의 「데이터 전처리하기」 ② 단계(내용을 단어별로 구분하는 단계)에서 한글 형태소 분석기의 종류를 바꿔 보자.

import konlpy                       # 한국어 정보 처리를 위한 파이썬 패키지
from konlpy.tag import Okt          # 한글 형태소 분석기 중 okt를 사용
okt = konlpy.tag.Okt()              # 형태소를 분석하여 okt에 저장
data2 = okt.nouns(data1)            # data1에서 명사(nouns) 추출해서 data2에 저장
data2                               # data2 내용 출력

결과(교과서 화면의 앞부분): '먼저', '기후', '위기', '대응', '위', '에너지' … 「기후」와 「위기」로 나뉘어 나와요.

형태소란 말의 형태를 지닌 요소이며, 의미를 가진 가장 작은 말의 단위로 더 나누면 뜻을 잃어버려요. 형태소 분석기를 변경해서 작업해 보니 단어 추출 방법이 달라져 출력된 결과가 달라진 것을 확인할 수 있어요.
💡 TIP · 형태소 분석을 위한 파이썬 라이브러리 코엔엘파이(koNLPy)는 한글 자연어 처리를 쉽고 간결하게 처리하도록 만들어진 오픈 소스 라이브러리예요. Hannanum, Okt, Kkma, Komoran, Mecab이라는 형태소 분석기를 제공하고 있으며, 형태소 분석기에 따라 분석한 결과가 달라져요.

데이터 분석의 사회적 가치

교과서 105쪽 · 사회적 가치의 뜻, 자료 5 분야별 사례

쉽게 말하면사회적 가치는 우리 사회 모두에게 도움이 되는 가치예요. 데이터를 분석하면 환자를 더 잘 치료하고, 재난에 미리 대비하고, 범죄를 막는 데 쓸 수 있어서 사회에 큰 가치를 줘요.

📖 사회적 가치란? (105쪽)

사회적 가치란 사회, 경제, 환경, 문화 등 모든 영역에서 공공의 이익과 공동체의 발전에 기여할 수 있는 가치예요.

[자료 5] 데이터 분석의 사회적 가치

🏥 의료 분야환자의 상태와 가족력 등을 분석하여 맞춤형 의료 서비스를 제공한다. / 빅데이터를 분석하여 질병을 원천적으로 차단하는 예방 의료를 실시한다.
🌪️ 재난 관리 분야빅데이터를 분석하여 기상 정보 및 지질 정보를 추정한다. / 기온과 상대 습도의 조합을 계산하여 폭염 특보와 건강 관리 정보를 제공한다.
🚓 범죄 예방 및 수사 분야과거에 발생한 범죄 수법, 시공간 환경적 통계 정보를 분석한다. / 범죄 발생을 미연에 방지하는 범죄 예측 서비스를 운영한다.
데이터 분석은 다양한 분야의 현상을 합리적으로 해석하여 문제를 해결하고 미래를 예측하는 데 도움을 준다. 양질의 데이터를 수집하고 안전하게 관리하여, 데이터를 분석하고 활용하는 과정을 통해 데이터의 사회적 가치를 확대할 수 있다.

비정형 데이터(텍스트)는 수집한 뒤 내용·줄바꿈·개인 정보를 살펴 정리하고, [^가-힣] 정규 표현식으로 한글만 남긴 다음 형태소 분석기로 명사를 뽑아 분석한다.
뽑은 단어에서 두 글자 이상만 남겨 빈도수를 세고 「단어: 횟수」 딕셔너리로 바꾸면 워드 클라우드에서 많이 나온 단어가 크게 나타나 핵심 키워드를 알 수 있다.
데이터 분석은 의료·재난 관리·범죄 예방 및 수사 분야에서 문제를 해결하고 미래를 예측하는 데 도움을 주며, 양질의 데이터를 안전하게 관리·활용할수록 사회적 가치가 커진다.
