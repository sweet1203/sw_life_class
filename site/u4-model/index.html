01

시뮬레이션 모델 살펴보기 준비

교과서 134쪽 · 자료 3 제작 소프트웨어, 넷로고로 모델 찾고 살펴보기

쉽게 말하면시뮬레이션 모델을 체험하거나 만들 수 있는 소프트웨어가 여러 가지 있어요. 이 단원에서는 그중 넷로고를 써요. 넷로고에서 모델을 찾고 → 화면을 살피고 → 코드와 설명을 확인하는 순서를 익혀요.

🧰 자료 3 · 시뮬레이션 제작 소프트웨어의 종류 (134쪽)

시뮬레이션 모델을 체험하거나 제작할 수 있는 소프트웨어에는 애니로직, 세이지모델러, 파이게임, 알고두, 넷로고 등이 있어요. 이름을 눌러 봐요.

💡 TIP · 넷로고 자연, 사회 현상을 시뮬레이션하는 데 유용한 시뮬레이션 소프트웨어로 생태학, 사회학, 교육 분야에서 사용되고 있어요. 오픈 소스로 무료이며 다양한 시뮬레이션을 탐색하고 구현할 수 있어요.

🔎 준비 학습 · 시뮬레이션 모델 살펴보기 (134쪽)

이 단원의 실습은 넷로고를 사용해 진행해요. 넷로고는 개체와 환경 사이의 상호 작용을 모델링할 수 있으며 시각적으로 확인할 수 있어요. 크롬에서 넷로고 사이트에 접속해요. 마우스를 우클릭하여 한국어로 번역해 사용할 수도 있어요.

1
모델 검색웹 브라우저에서 시뮬레이션 모델을 바로 탐색할 수 있는 [NetLogo 웹으로 이동]을 선택해요. 넷로고에는 다양한 시뮬레이션 모델이 내장되어 있어요. 그중 근육 발달 모델을 찾으려면 검색창에 'muscle'을 입력해요.
2
화면 구성 및 기능 탐색시뮬레이션하고 싶은 조건을 파라미터로 설정하고 [설정] 버튼을 누른 후, [가다] 버튼을 누르면 설정한 조건에서의 근육 발달 정도를 화면과 그래프로 확인할 수 있어요.
3
코드 및 모델 정보 확인모델이 어떻게 구현되었는지 알고 싶다면 [NetLogo 코드]를 눌러 코드를 확인해요. [모델 정보]를 누르면 그 모델에 대한 설명도 확인할 수 있어요.

TIP과 주의 카드를 눌러 확인해요.

🧩 어느 단계에서 하는 일일까? (체험)

한 장면씩 읽고 준비 학습의 세 단계 가운데 어디에 속하는지 골라 봐요.

02

모델 실행과 구성 요소

교과서 135쪽 · 자료 4 모델 실행 결과, 모델 탐색하기(화재)

쉽게 말하면넷로고 시뮬레이션 화면은 입력 데이터(조건) · 실행 횟수(틱) · 출력 결과(화면) · 해석 도구(그래프) 네 부분으로 이루어져 있어요. 조건을 넣고 → 시간이 흐르게 하고 → 결과를 화면과 그래프로 보는 거예요.

④ 모델 실행 (135쪽)

운동 강도, 수면 시간 등 입력 데이터를 한 가지씩 조작하여 시뮬레이션을 실행하고 결과를 확인해요. 넷로고의 시뮬레이션 모델은 어떤 구성 요소로 이루어져 있을까요? 모델을 탐색하며 생각해 봐요.

[자료 4] 시뮬레이션 모델 실행 결과 (근육 발달 모델 화면 모형 · 부분을 눌러 봐요)

교과서 135쪽의 화면을 보고 단순하게 다시 그린 모형이에요. 실제로 실행한 결과가 아니에요.

🧪 심화 · 한 가지만 바꿔 테스트 입력 데이터를 조작할 때 모든 값을 똑같이 한 뒤 한 가지 입력 데이터만 다른 값으로 설정해 테스트하면, 그 조건이 결과에 미치는 영향을 좀 더 확실하게 알 수 있어요.

🔥 해 보기 · 숲 화재 흉내 (135쪽 모델 탐색하기 · 화재)

교과서는 넷로고에서 화재(Fire Simple Extension 3) 모델을 찾아 실행해 보라고 해요. 여기서는 넷로고 기본 화재 모델의 규칙을 흉내 낸 작은 숲으로 구성 요소를 눈으로 확인해 봐요. (Extension 3의 추가 기능은 없어요. 진짜 모델은 교과서 QR로 열어요.)

규칙 숲(21×21칸)에 나무를 밀도만큼 심고, 왼쪽 끝 열에 불을 붙여요. 1틱마다 불붙은 칸의 위·아래·왼쪽·오른쪽 나무에 불이 옮겨 붙고, 불이 난 칸은 재가 돼요.
밀도는 [설정]을 누를 때 적용돼요.
틱 0 / 200탄 나무 비율 0%
나무 불 재 빈 땅

나무 밀도(입력 데이터), 틱(실행 횟수), 숲 화면(출력 결과), 탄 나무 비율(해석할 값)이 각각 구성 요소의 어디에 해당하는지 찾아봐요. 자동 재생은 200틱에서 멈춰요.

▶ 해 보기 · 같은 규칙을 파이썬으로 흉내 내기

위의 숲 화재 규칙을 파이썬 코드로 옮겼어요(15×15칸, 틱은 최대 100). 실행을 눌러 불이 번진 모습과 탄 나무 비율을 봐요. 그리고 DENSITY를 0.5, 0.6, 0.7로 바꿔 가며 비교해 봐요. (F는 아직 불이 남은 칸, x는 탄 자리, T는 남은 나무예요.)

난수를 쓰기 때문에 실행할 때마다 결과가 달라요. 그래서 같은 값으로 여러 번 실행해 비교해 봐요.

💭 해 보기 · 시뮬레이션 모델 탐색하기 (135쪽)

넷로고에서 화재 시뮬레이션을 찾아 실행해 보고, 시뮬레이션의 화면 구성·목적·구현 기능을 적어 봐요. 화재 모델은 교과서 QR 코드로 열 수 있어요.

03

근육 발달이 잘 이루어지는 조건 찾기

교과서 136~137쪽 · 모델 구현 5단계, 시나리오 비교

쉽게 말하면시뮬레이션 모델은 문제 정의 → 개념적 모델링 → 화면 구성 → 모델 구현 → 실행·결과 해석 다섯 단계로 만들어요. 근육 발달 모델로 이 단계를 하나씩 따라가 봐요. 현실을 중요한 것만 남겨 단순하게 만드는 일이 핵심이에요.

💪 실습 개요 (136쪽)

근력 운동은 남녀노소 모두에게 중요해요. 요즘 학생들은 운동할 시간이 항상 부족해요. 효율적으로 체력을 키우기 위해 규칙적인 시간을 들여 운동을 하면서 근육도 더 잘 생기도록 하는 방법은 무엇일까요?

문제 상황체력을 키우기 위해 운동을 해야 한다.
사용 소프트웨어넷로고(NetLogo)

1️⃣ 문제 정의 (136쪽)

시뮬레이션의 목적에 맞게 문제를 정의하고, 문제를 이해하기 위해 데이터를 수집해요.

2️⃣ 개념적 모델링 (136쪽)

개념적 모델링은 현상의 중요한 요인만을 추상화*하는 과정이에요. 근육 발달에 영향을 미치는 요소를 관찰하고, 그중에서 핵심 요소를 뽑아요.

현실 세계
추상화		시뮬레이션 목적운동을 통한 근육의 효과적인 발달
관찰 내용운동 강도, 운동 횟수, 수면 시간, 식사, 수분 섭취, 운동 사이 시간
핵심 요소운동 강도, 수면 시간, 운동 사이 시간

* 추상화 목적과 관련해 중요한 요인을 추출하고 관련 없는 요인을 제거해 현실 세계를 간소화하여 표현하는 것이에요. 같은 현실에서도 추상화 과정에 따라 모델의 구조와 변수가 달라질 수 있어요.

핵심 요소를 뽑은 뒤에는 핵심 요소의 이름을 정해요. 각각의 핵심 요소는 근육 발달과 어떤 관계가 있을까요? 핵심 요소를 사용해 시뮬레이션이 작동하는 전체 흐름을 설계해요.

② 시뮬레이션하고자 하는 [수면 시간]의 값을 조절한다.
