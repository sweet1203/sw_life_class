01

4단계 · 시뮬레이션 모델 구현

교과서 150~151쪽 · 작동 순서를 코드로 옮기기

쉽게 말하면버튼 하나마다 코드 한 덩어리(to ~ end)가 숨어 있어요. 버튼을 누르는 순간 그 덩어리가 위에서부터 차례로 실행돼요.

⌨️ 코드 창에서 모델 만들기

화면 구성이 끝났다면 코드 창에서 프로그램을 작성해 시뮬레이션 모델을 구현해요. 이번 모델은 사람들이 만났을 때 서로의 감정을 주고받아요. 시뮬레이션의 작동 순서를 생각하며 명령어를 써요.

  • to ~ end의 들여쓰기는 같은 선에 있어야 해요.
  • 여는 대괄호 [가 있으면 닫는 대괄호 ]도 있어야 오류가 나지 않아요.
  • 작동 알고리즘을 먼저 이해하고 나서 명령어를 써요.

명령문은 Code 창에 입력해요(143쪽에서 배운 Code 창). 이 웹 화면에서는 코드를 실행하지 않고 읽어 봐요.

🧮 시뮬레이션 작동의 알고리즘 (TIP)

작동 순서 ①~④
  1. 감정을 주고받기 전, 사람들은 회색이다. (가정: 기본 감정은 없다.)
  2. 감정을 주고받는 사람들은 랜덤으로 움직인다.
  3. 만약 두 사람이 만나면 감정이 전달되어 사람의 색이 바뀐다. (가정: 감정 전달은 무조건 이루어진다.)
  4. 위 ②, ③번의 과정을 반복한다.

「가정」은 모델을 단순하게 만들려고 정해 둔 약속이에요. 현실에서는 만나도 감정이 전해지지 않을 수 있지만, 이 모델은 일단 전해진다고 해요.

🧩 코드 6덩어리 살펴보기

버튼 이름을 눌러 설명 · 의사 코드(우리말로 풀어 쓴 순서) · 넷로고 코드를 비교해 봐요.

🐢 터틀은 움직이는 개체예요 (TIP)

터틀은 움직이는 개체로, create-turtles로 터틀들을 만들고 ask-turtles로 터틀들에게 명령해요. 나를 뺀 사람들은 humans로, 나는 users라는 터틀 종류로 나누어 따로 명령을 줄 수 있어요.

🎯 이 버튼을 누르면 어떤 코드가 실행될까?

설명을 읽고 알맞은 코드 이름을 골라 봐요.

03

5단계 · 모델 실행 및 결과 해석

교과서 153쪽 · 사람 수와 수용 정도를 바꿔 비교하기

쉽게 말하면값을 하나만 바꿔서 여러 번 실행하고, 결과가 어떻게 달라지는지 비교하면 모델을 해석할 수 있어요.

📋 실행 순서 (153쪽)

앞 단계를 거쳐 구현한 시뮬레이션 모델을 실행해 봐요. 아래 체험에서 단추를 누를 때마다 순서가 ✓로 바뀌어요.

🧪 감정 전염 시뮬레이션 (체험)

교과서 넷로고 코드와 같은 규칙으로 움직이는 흉내예요. 33×33칸 세상(가장자리는 반대편과 이어져요)에서 사람은 매 틱 자기 방향으로 0~4칸 걸어요. 노란(빨간) 사람과 같은 칸에 서면 그 색이 돼요.

입력 · 슬라이더와 버튼

W A S D 키로도 ‘나’를 움직일 수 있어요(이 화면이 보일 때만).

실행 · go
노란색 수용 정도

자동은 최대 300틱에서 멈춰요. 수용 정도 30%는 아래 「해 보기」의 심화 규칙이에요.

즐거움(노랑) 0

number수용 정도틱노랑빨강모두 같은 색?

처음 상태로 돌아가려면 [set up]을 눌러요. 사람의 처음 위치와 방향은 무작위라 같은 값으로 실행해도 결과가 달라져요.

🔍 1. 한 가지 감정 확산 관찰하기 · 2. 두 가지 감정 확산 관찰하기 (153쪽)

실행 순서에 따라 모델을 실행해 봐요. number 값을 10으로 했을 때와 100으로 했을 때를 각각 실행하고, 그래프 모양을 그려(적어) 봐요.

이번에는 [즐거움]과 [고마움] 두 가지 감정을 함께 관찰해요. ‘나’를 위, 아래, 오른쪽, 왼쪽으로 움직여 나의 감정을 퍼뜨려 보고, number 값도 바꿔 실행해 봐요.

TIP · 모델 실행 속도 조절 방법모델이 너무 빠르게 실행되면 감정이 확산되는 정도를 관찰하기 어려워요. 넷로고에서는 [go] 버튼을 누르기 전 [ticks] 위에 있는 파란색 막대를 slower로 옮겨 속도를 느리게 해요. 위 체험의 「자동 실행 속도」 버튼도 같은 역할이에요.

👥 인구 밀도에 따른 감정 전달의 변화

이 모델은 인구 밀도에 따른 감정 전달의 변화를 관찰할 수 있어요. 상호 작용하는 사람의 수가 많아지면 감정의 확산 속도가 어떻게 달라지는지 알아보고, 개인 간의 상호 작용이 전체 사회에 어떻게 영향을 미치는지 해석해 봐요.

🐍 같은 규칙을 파이썬으로 흉내 내기 ① 사람 수 비교

교과서는 넷로고로 하고, 여기서는 같은 규칙(33×33칸, 자기 방향으로 0~4칸, 노란 사람과 같은 칸이면 노란색)을 파이썬 코드로 써 봤어요. 코드 맨 위의 NUMBER를 10에서 100으로 바꿔 실행해 비교해 봐요. 난수를 쓰므로 실행할 때마다 결과가 조금씩 달라요.

🐍 파이썬으로 흉내 내기 ② 수용 정도 100%와 30%

노란 사람을 만났을 때 노란색으로 바뀔 확률을 accept로 정해요. 100%(1.0)와 30%(0.3)를 차례로 실행해 걸리는 틱을 비교해요. 오래 걸리면 「300틱 안에는 …」이라고 알려 줘요.

🛠️ 해 보기 · 나만의 시뮬레이션 모델 재구성하기 (153쪽)

만든 시뮬레이션 모델에 145쪽 해 보기에서 적은 감정의 이름과 색을 적용해 버튼과 플롯, 모니터를 바꿔 봐요.

＋ 심화 · 감정 수용 정도 추가하기부정적인 감정은 더 빨리 확산하는 경향이 있다고 해요. 감정마다 확산 속도(수용 정도)를 다르게 할 수 있을까요? 아래 내용을 참고해 감정 수용 정도를 추가해 시뮬레이션을 재구성해 봐요.
100%일 경우 
if any? other turtles-here with [color = yellow]
[set color yellow]
노란색 타인을 만나면 나도 노란색으로 바뀐다.

04

시뮬레이션 모델 구현 활동 정리하기

교과서 154쪽 · 모델 분석 · 사례 적용 · 기능 확장

쉽게 말하면모델을 직접 돌려 보며 알게 된 점을 우리 사회의 사례에 대 보고, 모델에 새 기능을 더하면 어떨지 상상해 보는 시간이에요.

1️⃣ 모델 분석

감정 전염 시뮬레이션 모델 구현을 통해 내가 알게 된 점을 서로 이야기해 봐요.

2️⃣ 사례 적용

서로 이야기 나눈 내용을 정리하고, 모델 실행으로 알게 된 점으로 설명할 수 있는 사회 현상 사례를 찾아 이야기해 봐요.

알게 된 점 예1) 모든 사람이 같은 감정일 때, 단 한 사람만이라도 다른 감정을 가진다면 주변 사람에게 전파될 가능성이 조금이라도 커진다.
➜
사회 현상 사례 예1) 학교 폭력을 당하는 학생을 많은 친구들이 모른척할 때, 내가 먼저 다가가 도와주면 감정이 전달되어 도움을 주는 친구들이 늘어날 가능성이 커진다.
