# 학기 시작 체크리스트

1. **진도 수집 시트**: 메뉴 「📈 진도 현황 → 새 학기 시작」 → 지난 기록이 `보관_…` 탭으로 옮겨짐
2. **명단**: 새 「명단」 탭에 반 · 학번 · 이름 붙여넣기 (학생은 학번·이름만 넣고 반은 여기서 찾음)
3. **교사 코드**: 바꾸려면 「교사 코드 정하기」
4. **질문폼**: `forms/forms.json`의 `classes`(반 이름)를 이번 학기 반으로
5. **차시 운영표**: `course.json`에서 이번 학기 차시 번호·순서, 공개할 차시 `ready`
6. **수행평가**: `assessments/ideas/`에서 고르고, 이번 학기 안내 페이지 만들기
7. 빌드 → 점검 → push → 선생님 목록(`/teacher/`)에서 차시 열어 보기
