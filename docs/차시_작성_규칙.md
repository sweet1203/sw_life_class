# 차시 작성 규칙

## 만드는 순서
1. **설계표**: 화면별 개념 · 체험 · 퀴즈 · 교과서 쪽 → 선생님 확인
2. **제작**: 교과서 PDF 원문(교사용 교과서)을 기준으로. 내용 정리본과 다르면 원문을 따른다
3. **점검**: `tools/check.py` 오류 0, 로컬 미리보기로 학생 흐름 끝까지(학번 확인 → 화면 → 퀴즈 → 마무리), 폰 폭 375px 넘침 없음
4. **검토**: 별도 검토(내용 정확성·수업 흐름·코드) → 고침 → 선생님 확인 → `course.json` status를 `ready`로 → 배포

## 화면 틀
| 화면 | 들어갈 것 |
|---|---|
| 0 시작 | 핵심 아이디어(교과서 사례), 학습 목표, 핵심 질문, 학습 계획 메모 |
| 01~0N 개념 | `head`(번호·제목·교과서 쪽) → `easy`(쉽게 말하면) → 교과서 내용 카드 → 체험 1개 → 퀴즈 2~3문항 |
| 스스로/함께 해결하기 | 교과서 탐구 활동 메모, 주요 개념 정리(빈칸), 성취도 평가 |
| 마무리 | `key3` 요약, 핵심 질문 답, 퀴즈 결과표(`#result` `#quizReset`), 질문폼(`{{FORM_URL}}`), 메모 모아 보기(`#msum`) |

## 파일 약속
- `quiz.js`: `const QUIZ={화면번호:[{q,o,a,w}]}`만. `a`는 0부터. `QK`·`MK`는 빌드가 넣는다.
- `lesson.js`: 마지막에 `const MEMOLIST=[[키,이름],...]`와 `onShow[마무리화면]=()=>memoSummary('msum',MEMOLIST);`
- 메모 칸은 `<textarea data-memo="키">`. 학번마다 따로 저장되고 진도 현황판으로 전송된다.
- 공용 부품: `sorter(id,{cats,items,end})` 분류 게임 · `flipCards(id,items)` 뒤집는 카드 · `tabs` · `vote` · `chips(id,키,목록,여럿)`
