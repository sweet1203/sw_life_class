# 새 과목 만들기 (정보 교과 다른 과목으로 옮기기)

이 저장소의 **공통 틀**(화면 엔진·점검·빌드·선생님 목록·진도 수집기)은 과목과 상관없이 그대로 쓴다.
과목마다 바뀌는 것은 `course.json`(과목 이름·주소·반·차시)과 `lessons/`(차시 내용), `forms/forms.json`(질문폼)뿐이다.

## 0. 준비물 (선생님)
- 교과서 PDF — 가능하면 **교사용 교과서**(내용·용어의 기준, 교과서 오류 확인)
- 지도서·교수학습 및 평가 운영 계획서 (차시 배당·성취기준)
- 지난 학기 수업 자료(수업 사이트·질문폼·활동지) — 「기본 틀은 내가 한 차시 내용으로」
- 반 명단(반·학번·이름) — **시트에만** 넣는다. 저장소에는 넣지 않는다

## 1. 정할 것 (선생님 → Claude에게 알려 주기)
| 항목 | 예 |
|---|---|
| 과목명·학점·시수 | 데이터과학 · 3학점 48시간 |
| 교과서 출판사 | ○○ |
| 저장소·사이트 이름 | `ds_data_class` → `https://dsdataclass.vercel.app/` |
| 압축하거나 빼는 단원 | 인공지능기초의 「Ⅲ단원 3차시 압축」처럼 |
| 반 이름 | 데이터A, 데이터B … |
| 질문폼 ID 앞머리 | 인공지능기초는 `ai-`. 과목마다 겹치지 않게(`ds-`, `info-`, `sw-` 등) |
| 수행평가 | 아이디어 모음으로만 둘지 |

## 2. 뼈대 만들기 (Claude)
```bash
python3 tools/new_course.py ~/Documents/<과목폴더>/<저장소이름> --name "데이터과학" --site https://dsdataclass.vercel.app/
```
- 공통 틀을 복사하고 차시는 비운다. 교사 모드 확인값(`99999 이름`)은 그대로 가져간다.
- `course.json`에 단원·차시를 **전부 `todo`로** 깔아 둔다 (차시 ID = 주소, 한 번 정하면 바꾸지 않기).
- `course.json`의 `classes`, `forms/forms.json`의 `classes`에 반 이름을 넣는다.
- GitHub에 새 저장소(공개)를 만들고 push.

## 3. 시트·배포 연결 (선생님, 처음 한 번)
1. **진도 수집 시트**: 학교 계정에 과목별 새 스프레드시트 → 확장 프로그램 → Apps Script → `apps_script/Code.gs` 붙여넣기 → 배포 → 새 배포 → 웹 앱(실행: 나 · 액세스: 모든 사용자) → **웹 앱 주소를 Claude에게** → `course.json`의 `progressEndpoint`
2. 시트 새로고침 → 「📈 진도 현황」 메뉴 → 「교사 코드 정하기」 → 「명단 시트 만들기」 → 명단 붙여넣기(테스트 학생 `00000`도)
3. **Vercel**: 새 프로젝트 → GitHub 저장소 가져오기(설정은 `vercel.json`이 알아서) → 주소 확인
4. **질문폼 수집기**: 인공지능기초와 같은 수집기를 쓸지(폼마다 `course` 칸으로 구분됨), 과목별로 따로 둘지 정한다 → `forms/forms.json`의 `endpoint`

## 4. 차시 만들기 (단원 단위로 「○○ Ⅰ단원 진행해줘」)
Claude가 한 단원씩: 설계 → 제작(Opus) → 검토 두 번(Fable) → 고침 → 폰 폭(375px) 브라우저 시험 → `check.py` 오류 0 → **바로 공개(`ready`) 배포** → 노션 차시 DB 갱신.
- 차시 하나 = `lessons/<차시ID>/` (`screens.html` · `quiz.js` · `lesson.js` · `DESIGN.md` · `assets/`) — 자세한 약속은 `docs/차시_작성_규칙.md`
- 교과서 오류는 `DESIGN.md`에 남기고 화면에서 바로잡는다
- 코랩 실습은 라이브러리 버전 차이(sklearn·gdown 등)로 결과가 달라지지 않는지 확인
- 저작권이 있는 데이터(사진 등)는 저장소에 넣지 않고 드라이브 링크로

## 5. 노션 정리 (Claude)
「정보교과」 페이지 아래에 과목별 「운영 안내 페이지 + 차시 DB」(인공지능기초와 같은 모양).

## 6. 점검·운영 (선생님)
선생님 목록(`/teacher/`)에서 차시를 열어 보고 고칠 곳을 알려 주기 · 코랩 실습은 GPU 켜고 한 번씩 · 학기 시작은 `docs/학기_시작_체크리스트.md`

## 꼭 지키는 것 (모든 과목 공통)
- 저장소는 공개 — 명단·답변·점수, 채점 기준 상세, 시험 문항, 정답 해설은 넣지 않기
- 학생 화면에 차시 번호·날짜·사이트 주소·수행평가/채점/세특 문구 넣지 않기 (`check.py`가 잡음)
- 주소(차시 ID)는 바꾸지 않기
- 내용·용어는 교과서 원문 기준 · 퀴즈 보기는 짧은 것 → 긴 것, 극단어(항상·절대·모든) 금지, 정답 위치 고르게
- 질문폼 원본은 필요한 폼만 고치기(전체 다시 만들기 금지)
- 수집기 코드를 고치면 Apps Script **배포 관리 → 수정 → 새 버전**(「새 배포」 금지 — 주소가 바뀜)

## 과목 하나씩, 대화도 과목마다 따로
네 과목을 동시에 하면 검토·점검이 밀린다. 한 과목을 끝내고 다음으로. 새 과목은 새 대화에서 「`ds_ai_class/docs/새_과목_만들기.md` 대로 ○○ 과목 시작하자」로 시작하면 된다.
